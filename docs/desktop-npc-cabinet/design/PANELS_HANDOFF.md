## 1. 世界资料面板 · 第 1 步：档案柜框架 + NPC 面板

设计稿：`heijin-panels.html`（档案纸定稿），在主界面 v5 基础上叠加了面板层。
- **打开方式：** 点右侧 dock 的「人」打开 NPC 面板；其余 6 个按钮只展示外框和占位，内容后续单独设计。
- **链接直达：** `#panel=NPC`、`#panel=NPC&person=n3`。
- 右上角的「设计稿控制」只用于演示，**不要实现**。

### 范围
- **只改样式和外框交互。** 涉及的文件：
  - `Dialog.tsx`：新增面板容器，原组件保留
  - `GameScreen.tsx`：面板挂载位置与 dock 当前态
  - `NpcPanel.tsx`：只做 className 和结构上的小调整
  - `styles.css`
- **不改的部分：** 数据、存档、AI、各面板的业务逻辑。现有文案、按钮、aria、搜索、分页、星标、返回按钮、焦点处理全部保留。
- **只做 ≥901px。** ≤900px 继续用现有的模态框和移动端逻辑，移动端以后单独设计。
- **暂不改的弹窗：** 设置、公告、撤回确认，以及左栏的「人物档案 / 经济与资产」。后两个在第 2 步处理。

### 一、档案柜框架（7 个世界资料面板共用）
1. **位置**
   - `position: fixed`，`top: var(--bar)`，`left: var(--left)`，`right: var(--dock)`，`bottom: 0`。
   - 盖住中栏（正文和输入台）；顶栏、左栏、右侧 dock 保持可见、可点。
   - **色调为「档案纸」**：暖白纸面 `#E4DCCA`，叠一层很淡的纸纹噪点（SVG feTurbulence，透明度约 7%）；左侧有深色阴影 `-30px 0 60px -20px #000c`，不用 backdrop 模糊。顶边一条 1px 朱砂渐变线。
   - 面板内的颜色变量全部在 `.archive` 作用域内重新定义，不影响主界面：

     | 变量 | 色值 | 用途 |
     |---|---|---|
     | `--head` | `#1F1B17` | 标题、人名 |
     | `--text` | `#2B2723` | 正文、字段值 |
     | `--muted` | `#5F574C` | 次要文字 |
     | `--dim` | `#857B6C` | 标签、时间 |
     | `--card` | `#EFE8D9` | 卡片底 |
     | `--line` | `#2a26221f` | 分隔线 |
     | `--line-2` | `#2a262233` | 边框 |
     | `--gold` | `#8E6C25` | 只用于：当前选中、星标、主操作、分节标题前的小竖线 |
     | `--info` | `#2D5E7D` | 链接、跳转、层级标签、列表圆点 |
     | `--pos` | `#2F7A58` | 好感正值 |
     | `--neg` | `#A3412E` | 好感负值 |
     | 朱砂 | `#A3412E` | 印章、eyebrow、「特殊人物」胶囊；标题栏印章为实心朱砂、白字 |

   - 「本幕在场」这类状态胶囊仍用城市色，与深色混合 45% 保证纸面上可读。输入框底色 `#F8F4EA`。
   - 原则：**金色只给「当前 / 选中 / 星标 / 主操作」**，其余信息分别使用白（标题）、蓝（信息）、绿 / 赭（好坏）、城市色（场景状态）。
   - 打开动画：从右侧 28px 滑入并淡入，0.28s。
2. **面板切换**
   - 点 dock 上的另一个按钮，直接切换面板内容，不用先关闭。
   - 再点当前按钮、点「关闭」或按 Esc，都会关闭面板。
   - 当前面板对应的 dock 按钮加 `aria-current="true"`：印章填金，按钮左侧一条贴向面板的 2px 金色指示条。
3. **可访问性**
   - 用 `role="dialog"`、`aria-modal="false"`、`aria-labelledby` 指向标题。
   - 它是非模态面板，不做焦点陷阱，dock 必须能用 Tab 键到达。
   - 打开时焦点进入面板；关闭时焦点回到打开它的那个 dock 按钮。
   - 打开期间正文区域设置 `inert`。
   - `<h2>` 文本保持面板名不变（如「NPC」），关闭按钮的 `aria-label` 仍为「关闭资料界面」，现有 e2e 依赖这两处。
4. **标题栏**
   - 左起依次是：印章（面板对应的单字）、eyebrow「WORLD ARCHIVE · 0N / 07」、`<h2>` 面板名、副标题。
   - 副标题对应关系（新增文案，可以调整）：

     | 面板 | 副标题 |
     |---|---|
     | NPC | 人物名录 |
     | 势力组织 | 势力与机构 |
     | 地图 | 地点层级 |
     | 物品栏 | 随身与仓储 |
     | 世界事件 | 进行中的事 |
     | 历史时间轴 | 已发生的事 |
     | 记忆 | 主角的记忆 |

   - 右侧是「ESC」提示，加上原来的关闭按钮。

#### 通用部件
后续面板都要沿用这些部件，建议写成 CSS 类。

| 类名 | 用途 | 要点 |
|---|---|---|
| `.f-label` / `.f-input` / `.f-select` | 表单 | 小号灰色字距标签；输入框深底细边，聚焦时金边加 3px 光晕；`.search` 自带放大镜；`select` 用自绘金色箭头 |
| `.pill` | 状态胶囊 | 默认灰色；`.on` 用城市色并带发光点（在场、已知类状态）；`.gold`（特殊、层级）；`.warn`（失效） |
| `.sec` | 分节卡片 | 1px 细边、8px 圆角；标题用衬线、金色、字距 .22em，后面跟一条渐隐线；`scroll-margin-top` 给吸顶头部留位置 |
| `.dl` + `.detail` | 资料字段 | 两列 grid，每项为「5.6rem 标签｜值」，虚线分隔；长文本加 `.wide` 占满整行；空值显示暗色「未记录」 |
| `.entry` | 记录条目 | 卡片样式；正文用衬线；时间用等宽小字 |
| `details.fold` | 折叠 | 金色小三角，展开时旋转 |
| `details.sec` | 可折叠分节 | 右侧显示「展开 / 收起」 |
| `.chip-btn` / `.link-btn` | 跳转 | 关联对象的跳转按钮；文内链接是金色下划线 |
| `.meter` | 好感条 | -100 到 +100 的双向条，中线为 0；正值金色、负值赭红；`null` 时显示虚线底 |
| `.empty` | 空状态 | 虚线框、居中、暗色字 |
| `.pager` | 分页 | 居中排列：上一页、第 N 页、下一页 |
| `.status-line` | 操作反馈 | 金色圆点加文字，`role="status"` |

### 二、NPC 面板
**布局：** 左右两栏，左为名录 `clamp(270px, 26%, 330px)`，右为详情，两栏各自滚动。

**左：名录**
- 吸顶工具区：「人物名录 N」，下面依次是搜索框和「人物筛选」下拉。原 label 文案保留；两个控件各占一整行，避免 placeholder 被截断。
- 人物行（`.person-row`，原 `aria-label`、`aria-pressed` 不变）：
  - 圆形头像：特殊人物是金色外环。
  - 姓名用衬线；身份、关系各 1 行，超出省略。
  - 最后一行是「本幕在场 / 场外人物」胶囊，加最近互动时间（等宽字）。
  - 选中态：左侧 2px 金条，背景是金色渐隐。
- 星标按钮（`.npc-star`，原 aria 不变）：圆形透明按钮；☆ 为暗色，★ 为金色带光。
- 名录底部是「历史身份记录」折叠项，以及分页 `.pager`。

**右：详情**
1. **吸顶头部**
   - 4.4rem 圆形印章头像（外环用城市色）、姓名（1.85rem 衬线）、「特殊人物 / 普通人物」胶囊。
   - 下面一行速览：年龄、性别、当前位置、场景状态、最近互动。
   - 右侧是「关系倾向」卡：数值加 `.meter` 加「与主角关系：…」，旁边是星标按钮。
   - 头部底部是分节锚点导航：人物档案、联系与地点、特殊人物资料（仅特殊人物显示）、已知信息、记忆与总结。点击平滑滚动到对应分节；滚动时高亮当前分节，滚到底时高亮最后一项。
2. **人物档案**：`.dl`。外貌、性格、个人背景用 `.wide`。
3. **联系与常驻地点**：
   - 电话状态用胶囊表示：已掌握为 `.on`，失效为 `.warn`。
   - 常驻地点每行依次是：角色（住处 / 工作地点 / 经常活动）、地点、「主角已知 / 世界记录／主角未知」胶囊。
4. **特殊人物资料**：
   - 先显示待完善提示 `.pending`（左侧金线），然后是 `.dl`。
   - 「人物关系网」：两列卡片。每张卡依次是：名字（可跳转的用 `.link-btn`）、关系胶囊、「A 对 B 的好感：N」、`.meter`、描述。
   - 「关联任务」：金色圆点列表。
5. **已确认关联组织**：`.chip-btn`，点击沿用现有的 `onOpenOrganization`。
6. **香闺秘档**：显示条件和字段完全不变，用 `.sec` 加 `.dl` 呈现；未建立时显示 `.empty`。
7. **创角原始设定**：`details.sec`，默认收起。
8. **人物已知信息 / 人物记忆与总结**：沿用 `RecordList`，只换外观。
   - 搜索框和「N 条记录 · 每页 20 条」放在同一行；条目用 `.entry`。
   - 记忆条目依次是：层级胶囊（金色）、认知类型、等宽时间加可见性说明、正文、「来源与认知」折叠。
- 未选中人物时显示 `.empty`：「选择人物，查看完整资料与独立认知。」
- 星标保存的反馈（`npc-feedback`）和「正在保存人物重要性…」用 `.status-line`，放在面板顶部。

### 验收要点
1. 1440×900、1280×800、1920×1080 下，面板不遮挡顶栏、左栏和 dock，页面无横向溢出；名录和详情各自滚动。
2. 7 个 dock 按钮能来回切换面板，当前态正确；Esc、关闭按钮、再点当前按钮都能关闭；关闭后焦点回到 dock 按钮。
3. NPC 面板原有的全部字段、文案、搜索、筛选、分页、星标、关系网跳转、组织跳转、RecordList 搜索与分页都可用。现有 e2e 只调整选择器，不改断言含义。
4. 特殊人物和普通人物、有好感值和好感值为 `null`、有数据和空数据，各种组合下版式都正确。
5. reduced-motion 下没有滑入动画和平滑滚动。

## 2. 世界资料面板 · 第 2 步：人物档案 + 势力组织

### 范围

- **只做 ≥901px。** ≤900px 保持现状。

### 一、人物档案
**标题栏：** eyebrow 用「PROTAGONIST · 主角档案」，副标题是「主角 · {姓名}」（新增文案）。印章字为「档」。

**身份卡（顶部通栏 `.pf-id`）**
- 左：证件照框，5.6×7rem，斜纹底加内虚线框，中间是姓名首字，朱砂色。

- 右：原来的三个入口按钮「经济与资产 / NPC 人物资料 / 切换存档」，竖排，右侧带 → 或 ↗。
- 卡片中间盖一枚斜的朱砂圆章「主角」，纯装饰，`aria-hidden`；1199px 及以下隐藏。

**下方两栏**（`grid: 1fr | minmax(300px, 34%)`，1199px 及以下合为一栏）

  - 「基本资料」：姓名、年龄、性别、职业、外貌、性格、背景。外貌、性格、背景占满整行。

    - 字段：当前时间、候选时间、地点、天气、环境。
    - 当前时间用等宽大字。
    - 候选时间只在存在时显示，用金色，文案「（未正式结算）」保留。
  - 「状态」：2×2 小卡，每张卡左边的色条代表一个状态：身体为绿、情绪为蓝、社会状态为金、法律状态为赭红。
  - 「当前穿戴与装备」：7 个单列槽位，依次为图标格、类别、物品名。
    - 图标格用单字：衣、裤、鞋、饰、武、副、车。
    - 值为「无」时，槽位改为虚线边、暗色字。
- **字段完整性：** 原 `profile-details` 的 16 个字段全部保留，只是分到了「基本资料」「此时此地」「状态」三处。Detail 标签文案不变（测试依赖）。

### 二、势力组织

**组织类型色**（新增，仅用于面板内）

**左：名录**
- 吸顶工具区：「势力档案馆 N」、搜索组织、组织类别下拉（选项后面带数量），文案不变。

  - 概况最多 2 行。
  - 最后一行是「与主角：…」。
  - 选中态：类型色淡底，色条加描边。

**右：详情**
1. **吸顶头部**
   - 4.4rem 方形徽章：类型色实心底，白色首字，有内框。

- 左右两栏：左侧为地点层级树 `clamp(250px, 24%, 300px)`，右侧为「城区示意 + 地点卡」；两栏各自滚动。
- 1199px 及以下：左栏为 220px，地点卡里的两栏合为一栏。

### 一、左：地点层级树
- **顶部：**
  - 原有的说明文字。
  - 「搜索地点」（新增，已确认要做）：前端按名称过滤，命中项的祖先节点自动展开。
- **树：** 原 `ul.map-tree` 嵌套结构不变。
  - 每层缩进 1rem，左侧一条虚线引导线。
  - 每个节点是一个按钮行，从左到右依次是：
    - 展开箭头：有子节点时显示，可点击，加 `aria-expanded`。
    - 名称：过长时省略，`title` 放全名。
    - 「你」标记：仅主角当前所在地点显示，朱砂小圆章。
    - 子孙数量：等宽小字。
  - 叶子节点没有箭头，换成一个小圆点。
  - 根节点（城市）名称用衬线，字距加宽。
  - 选中态：浅金底，左侧 2px 金条。
- **默认状态：** 选中主角所在地点，它的整条祖先链自动展开。
- **定位主角：** 主角位置从 `protagonist.locationId` 开始，沿 `parentId` 一路找上去，并做防环处理（与主界面面包屑同一套逻辑）。

### 二、右上：城区示意 `.city-map`
- **整体样式：** 方格纸底，28px 网格，背景色 `#EEE7D6`，10px 圆角。
- **头部：**
  - 城市名（衬线、宽字距）、英文名（城市色）、「地点层级示意」。
  - 右侧图例：「你 = 主角所在」「虚线框 = 区域」「◆ = 具体地点」。
- **展示范围：** 选中地点所在的根城市。
- **排版规则**
  - 根城市的每个子节点画成一个区域框：虚线边，半透明纸色底，`flex: 1 1 15rem` 自动换行。框的标题是名称和「N 人」（该区域下所有在此人物的数量）。
  - 区域内的每个子节点画成一个小街区卡。
  - 街区下面所有的叶子地点都铺成「◆ 地点」小胶囊；有人物时，后面带一个小数字。
  - 层级超过 3 级时，中间层不再单独画框，叶子地点直接归到街区卡下面。
- **高亮**
  - 选中链路上的区域和街区：金色实线边。
  - 主角所在区域：朱砂色虚线边，并在标题上加「你」。
  - 主角所在地点：胶囊为朱砂字，图钉做呼吸动画。
- **城市特色**：背景上画一条半透明的江。江水颜色随城市色变化，纯装饰，`aria-hidden`。
  - 重庆：长江和嘉陵江交汇。
  - 上海：黄浦江。
  - 哈尔滨：松花江。
  - 广州：珠江。
  - 其他城市不画江。
  - SVG 路径见设计稿 `RIVERS`。
- **交互：** 点区域、街区或地点胶囊，都会选中对应地点，同时同步左侧树的展开和选中状态。
- 根城市没有子节点时，显示 `.empty`：「该城市尚无下级地点记录」。

### 三、右下：地点卡
1. **面包屑**：除最后一级以外都可点击，点击即选中该级。
2. **标题行**
   - 名称（1.75rem 衬线）。
   - 级别标签：根为「城市」；有子节点为「区域 · 第 N 级」；叶子为「具体地点」。
   - 主角位置标签：选中的就是主角所在地点时，显示「你 · 主角当前所在」；主角在该区域之内时，显示「主角在此区域内」。
3. **下级地点**：子节点做成按钮，后面带子孙数量。
4. **此地人物**（前端汇总）
   - 「按人物当前位置汇总」：取 `npc.locationId === 此地` 的人物，每行依次是头像印章、姓名（链接，跳到 NPC 面板）、在场或场外胶囊。
   - 「常驻于此」：从 `usualLocations` 中筛出指向此地的记录，后面带角色胶囊（住处 / 工作地点 / 经常活动）。
   - 主角**不**通过 `knownToProtagonist` 过滤，与 NPC 面板的展示口径保持一致。
5. **此地动态**（前端汇总）
   - 事件：取 `event.locationId === 此地` 的事件，带状态胶囊，可以跳到世界事件。
   - 资产：取房产和车辆中 `locationId === 此地` 的项。
   - 都为空时显示 `.empty`。
6. **地点资料**（原 `WorldRecord`）：`details.sec`，默认收起。

- 汇总只看「此地」本身，不往下累加子孙地点，避免同一个人被重复计数。区域框上的「N 人」才是包含子孙的总数。

### 验收要点
1. 1440×900、1280×800、1920×1080 下无横向溢出；左右两栏各自滚动。
2. 一个地点在树、示意图、面包屑、下级地点四个入口中被选中，四处的状态都同步。
3. 多个根城市、空城市、层级 5 级以上、`parentId` 指向不存在的地点、`parentId` 成环，这些情况都不能报错。
4. 跳到人物和事件后，对应面板能定位到目标记录。
5. reduced-motion 下，主角图钉不做呼吸动画。

## 6. 面板设计 · 第 6 步：设置

设计稿：`heijin-panels.html`。

- **链接直达：** `#panel=设置`。
- 档案柜框架、档案纸色调和通用部件沿用 第 1 步。

### 范围
- **只改外观和容器。** 设置的校验、保存、脏状态（未保存修改）、切换拦截、凭证处理逻辑都不变，所有文案不变。
- **只做 ≥901px。**
- **打开方式：**
  - **游戏内**：放进档案柜面板，dock「设」进入当前态，与世界资料面板共用切换逻辑。
  - **首页**：首页没有档案柜，继续用居中弹窗，内部组件和样式完全相同（即 `.modal` 套档案纸色调）。
- **标题栏：** eyebrow 为「SYSTEM · 系统」，副标题为「本地偏好与 AI 渠道」（新增文案），印章字为「设」。

### 布局
左为分类栏 12.5rem，右为内容区。内容区分两部分：上面是可滚动的正文，下面是固定的保存栏。1199px 及以下：分类栏为 10.5rem；表单行改为上下排列。

**左：分类栏 `.settings-nav`**（`aria-pressed` 不变）
- 每一项依次是：单字小方印（连 / 词 / 忆 / 运 / 管，新增装饰）、分类名，以及有未保存修改时显示的赭红小圆点（新增，与现有的 dirty 状态同步）。
