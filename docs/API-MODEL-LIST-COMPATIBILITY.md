## 背景与目标

实际体验中，部分 API 中转站无法列出模型，部分只返回少量条目。原因尚不明确，可能涉及端点 URL、CORS、返回格式、权限、分页或客户端过滤。不要假定所有问题都能在客户端修复。

已有参考项目的研究线索：`WJT111222/MoRanJiangHu`、`qianye60/XianTu`、`1102052563-a11y/zhushen-space`、`qiwu622/naruto-rpg`、`Ekibenya/Cat`、`LingYuYue1/KaiTuoYiShi`、`RedCliffScribe/chronicles-of-chaos`、`0xSynt4x/MyRaidRealmWEB`。仅借鉴思路，勿整套搬运。

**范围**：只修复模型列表获取及必要兼容，不重构游戏界面、回合工作流、Prompt、Thinking、存档 Schema、生成 URL 或正文 POST 请求。

## P0-A：列表 URL 与请求边界

1. 规范化末尾斜杠以及误填的完整 `/chat/completions`、`/models` 路径；保留合法自定义中转路径，不能强加 `/v1`。
2. OpenAI-compatible 可有限尝试有根据的**同源**候选列表端点；拿到有效结果立即停止。
3. HTTP 401/403/429 不作暴力路径探测；不能把 Key 发到不同域名，不能在凭证被 URL/重定向暴露的情况下继续。
4. 不改变正文生成所用的实际端点；不得将“模型列表失败”当作需要付费生成探测的理由。

## P0-B：返回数据与模型 ID

- 标准 `data[].id`；在确认结构下可识别 `models[]`、顶层数组、合法字符串 ID，或有明确语义的 `id` / `model` / `name` 字段。
- **原始请求模型 ID 与展示名区分**，不可为了显示漂亮擅自改写真实 ID。去重、保留合法值。
- 复核 `src/services/ai/configuration.ts` 的 `modelIdSchema` 是否错误剔除真实合法 ID；如修改，须同步检查请求快照、四阶段路由和存档校验，不能只放松前端。
- 现行原生 Gemini / Anthropic 的分页、能力元数据读取不退步；异常/循环/截断分页应明确报告。

## P0-C：准确、脱敏的诊断

显示或记录必要的安全诊断：最终**同源**端点（去除凭证与敏感查询）、HTTP 状态码、原始条目数、成功解析/合法模型数、过滤数量、发现分页与是否完整。

明确区分：认证/权限、路径不存在、网络或疑似 CORS、JSON/结构不兼容、成功但返回空表、服务器本来限制列表、分页失败。不要泄露 Authorization、Key、响应敏感原文或借助虚构预设模型冒充成功。

## P0-D：PR #25 的配置与 UI 保护

- 四阶段选择、同渠道缓存、手填模型和已选合法 ID 保留。
- 刷新失败不清空当前选模、不自动切第一项；旧请求/取消/切渠道不会覆盖新结果。
- 不无依据过滤图片模型或自称识别所有模型能力；可提醒：模型列出 ≠ 可以生成正文。
- **不得发真实付费生成请求来枚举模型。**

## P1：CORS 方案（仅确有必要时研究）

先证明浏览器真实 CORS 阻塞，并核实站点的 Cloudflare Workers 环境能否承载**动态**转发。若确须代理，仅考虑经过用户同意的本站同源、明确路径且限流的**模型列表 GET**，并确保：

- 只转发受约束的 HTTPS 上游，阻止内网、回环、保留地址、本站自身与危险重定向，避免 SSRF；
- 限定接口方法/请求数/超时/响应体大小，并做好脱敏处理；不留存或记录明文 Key；
- 玩家获知请求经过本站转发；认证失败不得通过代理绕过；
- Worker 如仅支持静态资产，则明确报告无法实施，不能虚报部署成功；
- **绝不为正文生成 POST 增加自动代理重试**，避免重复计费与取消语义破坏。

## 验收

全部使用 Mock，不调用真实收费模型。覆盖：

- URL 格式、路径候选、不同 JSON 布局、ID 校验/去重；
- 正常/空列表、401/403/404/429、分页正常/异常、网络/CORS、超时和取消；
- 无跨域 Key、脱敏诊断、旧渠道兼容、四阶段缓存/切渠道/手动 ID；
- Gemini/Anthropic 原有分页与普通游戏生成回归。

完成 `npm run lint`、`npm run typecheck`、`npm run build`、相关单测和 Chromium E2E；未测真实服务行为明确标为待手工验证。**独立开发分支 + Draft PR；用户审查后决定合并或部署。**
