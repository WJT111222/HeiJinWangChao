### 须知第四章定稿

1. 请勿在游戏输入、剧情或导入资料中填写真实姓名、联系方式、证件号码等敏感个人信息。
2. 生成内容时，玩家输入、必要的游戏状态和剧情上下文可能经网络发送至当前配置的服务地址；连接测试也会发起网络请求。
3. 请妥善保管 API 密钥，不要将密钥写入剧情、存档、截图或公开分享的资料。浏览器存储并非安全密钥库。
4. 网络传输和接收端的数据处理不完全由本游戏控制；请了解相应的隐私规则，仅提交必要信息。

保留六章结构、其他五章、开头、强调和开发者落款；第五章原有 Demo 测试版/存档原文按用户“原则上不改”要求保留，未顺带重写版本措辞。独立定稿夹具 `disclaimer-v1.md` 仅替换第四章，不从生产对象自动生成预期。
