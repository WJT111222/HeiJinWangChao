# 手机端 · 游玩须知与王朝公告 交接文档

设计稿：`heijin-mobile-notices.html`。背景是开场页面（车票）的 iframe，只用来演示，不需要实现。

**链接直达**

| hash | 内容 |
|---|---|
| `#d-auto` | 自动弹出 · 须知 |
| `#a-auto` | 自动弹出 · 公告 |
| `#d-man` | 手动打开 · 须知 |
| `#a-man` | 手动打开 · 公告 |

在后面加 `&y=900` 或 `&y=end`，可以直接滚到正文的对应位置。

## 原则

- **只改 ≤900px**；电脑端照旧按 `NOTICES_HANDOFF.md` 实现。两端是同一个组件，用 CSS 和少量条件渲染区分。
- `useNotices` 的逻辑完全不变：
  - 首次进入时，先弹须知，关闭后接着弹公告；
  - 「今日不再弹出」的读写方式不变；
  - 从首页或设置手动打开时，只显示一张。
- **正文一字不改**，`disclaimer-content.test.ts` 照常通过。
- 以下这些照原样保留：
  - 所有 `aria-label`：关闭免责声明、关闭王朝公告、免责声明内容、公告内容、仅限 18 岁及以上；
  - 类名 `notice-age` / `notice-theme` / `notice-message` / `notice-footer` / `notice-content`；
  - 焦点陷阱，以及关闭后焦点回到原位置。
- 手机端新增的装饰文案：
  - 「— 全文完 —」；
  - 章节胶囊里的「已阅读 N%」（电脑端已有）；
  - 章节胶囊上的标题，是从原章节标题去掉开头的「一、」等序号得到的，不是另写的文字。

## 外观

- **整屏文书：** 不用居中的弹窗，改为从底部升起，顶端离安全区 8px，几乎占满整个屏幕。
  - 顶部 22px 圆角，顶边一条金色渐变细线；
  - 背景是深色渐变 `#141816 → #0d100f`，后面的首页压暗并模糊；
  - 入场时上移 40px 并淡入，用时 0.4s。
- **结构：** 从上到下依次是抓手、头部、步骤条、章节横条（只有须知有）、正文、底栏。只有正文区域可以滚动。
- **配色：** 沿用电脑端的黑金版：
  - 金色渐变标题；
  - 正文 `#D9D4C6`；
  - 强调段落 `#F1E6C8`，左边加金线和浅金渐变底；
  - 18+ 印章用赭红 `#D47C60`。

### 头部

- 依次为：金描边方印（须知用「须」，公告用「诏」）、小字 eyebrow（HEIJIN · NOTICE / BULLETIN）、标题（单行，超出部分省略）、圆形 ×。
- 打开时焦点落在文书容器上（`tabindex=-1`，不显示描边），不要直接落在 ×，避免一打开就出现金色焦点环。

### 步骤条

只在 `automatic` 时显示，显示为「1 须知 — 2 公告」：

- 当前步骤：金色实心；
- 已完成的步骤：金色描边加 ✓；
- `aria-label` 为「首次弹出 N / 2」。

## 一、游玩须知

### 章节横条（替代电脑端左侧目录）

- 6 个章节胶囊排成一行，可以横向滑动，每个胶囊前面带小号的「一 … 六」。
- **点击胶囊：** 正文平滑滚动到对应章节，`scroll-margin-top` 留 0.6rem。
- **滚动高亮：** 当前章节的胶囊变成金色实心，并自动滚到横条最左边。滚到底部时，高亮最后一节。
- **阅读进度：**
  - 横条底边有一条 2px 的金色进度线；
  - 横条右端固定显示「已阅读 N%」（下面垫一层渐隐底）；
  - 两者都只是提示，**不作为关闭的前提**。

### 正文

- **年龄提示块：** 赭红描边，内容依次为 3.4rem 的「18+」圆印（倾斜 −10°）和粗体 `ageNotice`。`ageNotice` 去掉开头的「｜」，读屏文本保持原样。
- **段落：** 衬线字，1rem，行高 2，两端对齐。
- **章节标题：** 金色衬线字，后面接一条渐隐线。
- **结尾：**
  - 原来的 `<hr>` 换成 ◆ 分隔；
  - 前两段居中；
  - 「《黑金王朝》开发者」右对齐，旁边加一枚「黑金王朝」方印（装饰）；
  - 最后是「— 全文完 —」。

## 二、王朝公告

- **版本胶囊：** 「VERSION x · 开发里程碑」，版本号从数据里取，**不要写死**；取不到时整个胶囊不显示。
- **`.notice-theme`：** 衬线字，1.32rem。
- **更新条目：** 改成**竖向时间线**：
  - 左侧圆形序号，依次用壹、贰、叁……，金色描边；
  - 序号之间用一条渐隐金线连起来；
  - 条目正文用无衬线字，0.88rem，行高 1.85。
- **`.notice-message`：** 浅色卡片，衬线字，前后加金色「」。
- **结尾：** 右下角一枚「黑金王朝」方印。

## 底栏（两张共用，`.notice-footer`）

- 固定在底部，包含安全区。
- **左侧：** 「今日不再弹出」，自绘方框，勾选后变成金底加深色 ✓；逻辑不变。
- **右侧：** 金色主按钮，占剩余宽度，点击效果和 × 相同（都是 `onClose`）。

| 情况 | 按钮文案 | 附加 |
|---|---|---|
| 自动弹出 · 须知 | 已阅读，查看公告 → | 按钮上方右对齐一行小字「关闭后将显示王朝公告」 |
| 自动弹出 · 公告 | 开始游玩 | — |
| 手动打开 | 关闭 | — |

## 须知 → 公告的切换

自动流程里关掉须知之后，**不要先整张收起、再重新升起一张**：

- 须知向左退出 30% 并淡出；
- 公告从屏幕右侧滑入。

两者同时进行，用时 0.45s，看起来像翻到下一页。实现时可以在同一个外壳里切换内容，也可以让两个对话框交替播放动画，具体方式由 Codex 决定，只要 `useNotices` 的调用顺序不变。

**reduced-motion：** 关闭所有动画。

## 验收

1. 首次进入的流程、静音逻辑、手动打开的行为都和现在一致。
2. 正文与 `disclaimer-v1.md` 测试夹具逐字一致。
3. 章节胶囊的跳转、高亮、进度显示正确，在 375×667 下也能横向滑动。
4. 底栏始终可见，正文不会被底栏或头部遮住。
5. 焦点陷阱、Esc 关闭、关闭后焦点回到原位置，都和现在一致。
