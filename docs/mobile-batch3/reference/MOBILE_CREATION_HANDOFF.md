# 手机端 · 创建角色 交接文档

设计稿是 `heijin-mobile-creation.html`。

**用 hash 打开指定状态**

| hash | 效果 |
|---|---|
| `#s=1` 至 `#s=5` | 跳到对应步骤 |
| `#blank` | 空白新档 |
| `#err` | 校验错误 |
| `#s=2&custom` | 自由选择职业 |
| `#s=3&city=shanghai` | 切换城市 |
| `#pack` | 打开开局包 |
| `#s=5&pack` | 打开保存为开局包 |
| `#preview` | 展开完整车票预览 |

## 设计思路

这一页接在开场后面：玩家撕下「空白车票」就进入这里。**五个步骤，就是在这张车票上逐项填写。**

- **实时小车票（页面顶部）**：填写时同步更新。
  - 姓名写在 FROM，城市写在 TO；
  - 第 3 步选定城市后，票头换成该城市的颜色。
- **五站进度**：五个步骤画成一条线路。
- **最后一步**：车票盖上「待开局」章。和开场一样，撕下票根即可确认创建存档。

## 原则

- **只改 ≤900px。** 电脑端照旧使用 `CREATION_HANDOFF.md`。
- **业务逻辑完全不变：**
  - 五个步骤、全部字段、`validateStep`、`selectProfession`、模板套用；
  - 预设职业不显示「个人技能与专长」，`skillsSource` 置为 `automatic`；
  - 提交流程，开局包的 6 个视图。
- **文案**全部沿用电脑端。下面这些是手机端新增的装饰文案：

  | 位置 | 新增文案 |
  |---|---|
  | 顶栏 | 「空白车票 / NEW LIFE」「‹ 首页」 |
  | 小车票 | FROM / TO、STATION、「展开 ›」 |
  | 车票预览 | 「车票预览」「待开局 BOARDING」「↓ 按住票根往下撕 · 可能产生第三方 API 费用」「填完第 5 站即可撕票」 |
  | 五站进度 | 简称：基本 / 职业 / 城市 / 同伴 / 确认 |

- **人物卷宗：** 电脑端右栏的人物卷宗，在手机端由顶部小车票承担，不再单独做。

## 页面结构（从上到下）

| 区块 | 说明 |
|---|---|
| 顶栏 | 「‹ 首页」（返回首页，草稿保留）、「空白车票」、开局包按钮。按钮在第 1 步显示「我的开局包」，第 5 步显示「保存为开局包」，其他步骤隐藏，规则和现在一致 |
| 实时小车票 | 高约 92px，固定不滚动，点击展开完整车票预览 |
| 五站进度 | 原 `nav.steps`，固定不滚动 |
| 表单区 | 唯一可以滚动的区域 |
| 底栏 | 固定在底部，包含安全区 |

### 实时小车票

- **布局：** 左侧 8px 竖色条是票头颜色；中间是路线和信息行；右侧票根以虚线和两个半圆缺口隔开。
- **FROM：** 显示 `person.name`，没填写时显示灰色「？」。
- **TO：** 第 3 步之前显示「？」，从第 3 步开始显示城市名。
- **信息行：** 年龄 · 性别 · 职业，有同伴时再接「同伴 X」。没填的项显示灰色占位字（年龄 / 性别 / 职业）。
- **票根：** 显示当前站号（01–05），下面一条完成度细条，规则和电脑端人物卷宗一致。
- **点击：** 从底部弹出「车票预览」，显示完整车票。这里的票根只提示进度，不能撕。

### 五站进度

- 五个圆点用一条线连起来，已经走过的路段用金线填满。
- **已完成：** 金色描边，里面显示 ✓。
- **当前：** 金色实心，外面加光晕。
- **点站名：** 往回点可以直接跳回；往前点要先通过校验（行为不变）。
- **无障碍：** 保留 `aria-current="step"`，每个按钮的 `aria-label` 是完整步骤名。

### 底栏

- 依次是：「←」上一步（第 1 步时禁用）、「0N / 05」、金色主按钮。
  - 第 1–4 步主按钮显示「下一步 →」；第 5 步显示「确认并创建存档」。
- **第 5 步：** 隐藏「05 / 05」，换成「可能产生第三方 API 费用」两行小字。
- 原有的禁用条件和「正在保存…」状态不变。
- **键盘弹出时：** 底栏贴在键盘上方。在输入框里按回车，等于点「下一步」（真实代码保留 `<form onSubmit>`）。

## 各步

**通用**

- **卡片头：** 「STEP 0N / 05」、步骤名，右侧是「填写内容自动保留」。
- **校验错误：** 用 `.alert.l-err`，放在卡片头下面，`role="alert"`。
- **输入框：** 字号一律 16px，避免 iOS 聚焦时页面缩放。年龄用 `inputmode="numeric"`。

**第 1 步 · 基本信息**

- 姓名：大号衬线，字距加宽。
- 年龄（6.2rem 宽）和性别「男性 / 女性」并排一行。性别底层仍是 radio。
- **外貌 / 性格：**
  - 模板是一排**可以横向滑动的胶囊**：「自由选择」加 6 个模板，`role="radiogroup"`。
  - 选中的胶囊会自动滚到这一排的中间。
  - 胶囊下面是原来的文本框。

**第 2 步 · 职业与能力**

- **导语：** 原文。
- **职业方向：** 一排横滑胶囊，5 个方向，最后一个是「✎ 自由选择」。保留 `aria-pressed`。
- **职业列表：** 单列卡片，每张显示职业名和前 3 个技能。底层是 `name="profession"` 的 radio。
- **选中后：** 卡片左侧亮起金边，**职业档案直接在这张卡片里展开**，依次是描述（衬线）、技能（蓝色标签）、长期影响。
- **自由选择：** 四个字段都是单列：职业名称、职业介绍、长期影响、内置职业技能。

**第 3 步 · 城市与背景**

- **城市卡片：** 单列 4 张。底层是 radio `name="city"`。
  - 卡片上部是 66px 的**防伪底纹带**，和开场车票是同一套 `guilloche()`，依次是：标签（城市色）、大号城市名、右侧城市简称圆章。
  - 卡片下部是城市描述。
  - **选中时：** 描边和外发光都换成城市色；圆章换成「起点」胶囊；整页顶部光晕和小车票的票头一起换色。
- **人物背景：** 原文本框，下面是「跳过背景，继续 →」。

**第 4 步 · 初始同伴**

- 开关卡：底层是 checkbox，样式做成手机上常见的胶囊开关。
- 开启后显示 8 个字段，单列排列。长文本字段用较矮的文本框。
- 底部是「跳过同伴，继续 →」。

**第 5 步 · 确认与开局**

**完整车票**

| 区域 | 内容 |
|---|---|
| 票头 | 城市色，「城市名 · 纬度 · NEW LIFE」 |
| 路线 | FROM 姓名 → TO 城市 |
| 信息行 | 年龄 / 性别 / 职业 |
| 防伪底纹带 | 坐标、意象词，盖一枚朱砂章「待开局 BOARDING」 |
| 票根 | 「确认并创建存档 · ↓ 按住票根往下撕 · 可能产生第三方 API 费用」 |

- **撕票根：** 拉动超过 60px 后松手，效果等于点「确认并创建存档」，走同一个提交方法，并且同样先校验 1–4 步。
- 震动和 reduced-motion 的规则和开场相同。

**回顾卡片**

- 四张可以折叠的卡片（`<details>`），第一张默认展开。卡片头显示序号、标题，右侧是摘要。
- 展开后是两列字段表，长文本最多 3 行。底部是原来的「修改…」按钮，样式为蓝色文字链接。
- 「外貌模板 / 性格模板」放在 01 卡片里。02 卡片保留「完整职业表单」说明。04 卡片显示「开局时间待确认」（金色等宽字）和原来的说明。

**其余**

- 开局偏好文本框。
- 费用提示：`.alert.l-info`，`id="opening-generation-notice"`，`aria-describedby` 关联不变。

## 开局包（底部抽屉）

- **我的开局包：**
  - 顶部提示：「套用后将替换当前创角草稿；开局包只保存在本机浏览器。」
  - 下面是单选列表，每项依次是首字方印、名称、「城市色圆点 + 姓名 · 年龄 · 城市」、选中圈。
  - 底部三个按钮：「删除」（赭红描边）、「重命名」、「套用开局包」（金色，占剩余宽度）。没有选中时三个都禁用。
- **套用、删除、覆盖确认：** 在同一个抽屉里换成确认内容。正文是原来的确认句，下面是「取消」和主按钮。删除的主按钮用赭红实心。
- **保存为开局包：** 「保存方式」是横滑胶囊（新建 / 覆盖：X），下面是名称输入框，限 80 字。
- **成功和失败提示：** 用顶部 toast 或 `.alert`，规则沿用 `FEEDBACK_HANDOFF.md`。

## 动效

- **切换步骤：** 表单内容从右侧滑入（返回时从左侧），0.3s。
- **在同一步内修改选项**（例如选模板、选职业、选城市）：不播放动画，并保持当前滚动位置。
- **reduced-motion：** 关闭所有动画。

## 验收

1. 在 375×667、390×844、430×932 三种尺寸下：小车票、进度条和底栏始终可见，只有表单区滚动；键盘弹出时底栏不被遮挡。
2. 五步的所有字段、校验、跳过、「修改」跳转、提交流程、开局包的 6 个视图都和电脑端一致。
3. 撕票根和「确认并创建存档」走的是同一个方法，校验失败时跳到出错的那一步。
4. 胶囊组、职业卡片、城市卡片、性别都可以用键盘操作。
5. 现有 e2e 只调整选择器。
