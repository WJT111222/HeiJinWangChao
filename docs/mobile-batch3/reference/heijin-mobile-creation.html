MOBILE · 空白车票

手机端 · 创建角色

从开场撕下「空白车票」进入。五个步骤就是在这张票上一格一格写字。

  1. 实时车票：顶部的小车票随填写实时更新，姓名写上 FROM，城市写上 TO，城市选好后票头变色。点一下展开完整车票。
  2. 五站进度：五个步骤画成一条线路，已过的站点亮起，可以点站名跳回。
  3. 单手填写：模板、职业方向都是横滑胶囊，职业列表点开后原地展开职业档案。
  4. 最后一步：车票盖上「待开局」章，和开场一样，撕下票根或点按钮都可以确认创建存档。
  5. 开局包：右上角「包」，从底部弹出。
