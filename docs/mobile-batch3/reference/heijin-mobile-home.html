封面和存档馆合成一屏：每份存档是一张开往某座城市的车票。

  1. 左右滑动翻车票：最后一张是「空白车票」，用来开启新的人生。
  2. 撕下票根进站：按住票根往下拉，撕下来就读取这份存档。下方的金色按钮做的是同一件事。
  3. 发车屏：顶部翻牌屏显示当前这张车票的终点、时刻和状态，翻到别的车票时会跟着翻动。
  4. 检票章：已选择的存档盖着朱砂「已检票」章，封面上的「继续游戏」进的就是它。
  5. 四城票头：分别呼应游戏内的回目铭牌，有轻轨条、搪瓷蓝、冰霜和霓虹。
