MOBILE · 档案纸面板

手机端 · 五个面板

这五个面板在手机上不能简单套用「列表 → 详情」，各自单独设计。都是从底部升起的档案纸全屏抽屉。

  1. 地图：不画整棵树，改成逐层下钻：面包屑在上，当前层的下级地点铺成方格纸上的区域块；右下角「定位到我」一键跳到主角所在。
  2. 经济与资产：现金做成一张黑金钱包卡；两个合计并排；收入 / 债务 / 资产三段切换。
  3. 历史时间轴：三栏改成单列时间线，用左边框颜色区分世界（蓝）与主角（朱砂），上方可筛选。
  4. 物品栏：分类横滑胶囊 + 三列物证标签，点物品从底部升起详情。
  5. 设置：像手机系统设置：分类列表 → 推入分类页；保存栏固定在底部。
