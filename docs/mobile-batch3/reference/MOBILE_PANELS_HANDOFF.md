## 原则

- **范围：** 只改 ≤900px。电脑端照旧使用 `PANELS_HANDOFF.md`。
- **不能变的：** 数据、文案、aria、派生值算法（未偿本金合计、资产估值合计、地点汇总），全部和电脑端一致。
- **新增展示字段：** 入账账户、到账时间、债务状态、到期日、车辆型号和车牌。规则和电脑端一样，数据为空时整项不显示。
- **容器：** 沿用主界面交接（`MOBILE_MAIN_HANDOFF.md` §5.3）的**档案纸全屏抽屉**：
  - 从底部升起，离顶部安全区 10px，圆角 22px，有抓手；
  - 标题栏依次为：朱砂方印、eyebrow、标题、×；
  - 进入二级页面后，方印换成「‹ 上一级」。
- **色板：** 用档案纸色板。

  | 用途 | 色值 |
  |---|---|
  | 纸 | `#E4DCCA` |
  | 卡片 | `#EFE8D9` |
  | 标题 | `#1F1B17` |
  | 正文 | `#2B2723` |
  | 当前 / 选中 | `#8E6C25` |
  | 信息 | `#2D5E7D` |
  | 正向 | `#2F7A58` |
  | 负向 / 朱砂 | `#A3412E` |

- **金额：** 一律使用 `money()`，格式为「3,280.00 元」。

**通用部件**

- **胶囊横条 `.chips`**：用于分类和筛选，横向滑动。选中态为深墨底白字，保留 `aria-pressed`。
- **分段控件 `.seg`**：两到三个选项的切换。选中项为卡片色底，字体加粗。
- **吸顶 `.sticky`**：分类条或分段控件随内容滚动，滚到顶部后吸顶。
- **子抽屉 `.sub`**：在面板抽屉里再从底部升起一层，用于物品详情和年代选择。最高 78%，点遮罩或下拉关闭。

## 一、地图：逐层下钻

手机上**不画整棵地点树**，改成像文件夹一样一层一层点进去。原来的 `.map-tree` 结构可以保留在 DOM 里，但在手机上隐藏；状态与示意图共用。

1. **搜索地点**：放在最上方。输入后，下面的内容整体换成结果列表，每条显示地名和上级路径胶囊，点击后跳到该地点。没有结果时显示「没有找到匹配的地点」（新增文案）。
2. **面包屑**：可以横向滑动，当前层加深色底，点任意一级回到那一层。
3. **城区示意 `.mapbox`**：方格纸底，画当前层的所有下级地点。
   - **布局：** 两列区域块，块内依次是名称（衬线）、「N 处地点 · N 人」、最多 4 个下级 ◆ 胶囊。
   - **点击区域块：**
     - 有下级的地点：进入下一层，并选中它；
     - 叶子地点：只选中，不进入。
   - **样式：**
     - 选中链上的块：金色实线；
     - 主角所在链上的块：朱砂边，右上角「你」章（呼吸动画）；
     - 叶子地点块：不显示 ›。
   - **江：** 按城市画在块的下层，和电脑端用同一套 `RIVERS`，只是缩放到这个比例，路径避开标题行。
   - **右下角「定位到我」**（新增，地图类 App 的习惯）：一键把视图切到主角所在地点的上一层，并选中主角所在地点。
4. **地点卡**：放在示意图下面，内容依次为：
   - 上级路径（小字）、名称；
   - 级别胶囊；如果主角在这里，再加「你 · 主角当前所在」或「主角在此区域内」；
   - 下级地点（胶囊加子孙数量）；
   - 此地人物：「按人物当前位置汇总」和「常驻于此」两组，点人名跳到 NPC；
   - 此地动态；
   - 地点资料（`details`，默认收起）。
5. **空状态：** 城市没有下级地点时，显示「该城市尚无下级地点记录」。

## 二、经济与资产

1. **钱包卡：** 深色黑金卡片，上方是「现」方印加现金（2rem 等宽金字）；用虚线隔开，下方一行是「线」方印加线上资金。
2. **两个合计：** 并排两张虚线卡。
   - 未偿本金合计：朱砂字，底注「N 笔偿还中」；
   - 资产估值合计：绿色字，底注「N 项资产」或「另有资产估值未确认」。
3. **分段控件**（吸顶）：「收入 N / 债务 N / 资产 N」，三段只显示其中一段，避免整页过长。
   - **收入：** 账本列表。第一行是来源（衬线）和金额，金额按状态区分：已到账为绿色并加「+」，待确认为蓝色，已取消为灰色加删除线。第二行依次是状态胶囊、入账账户、到账时间或预计时间、`scheduleText`。
   - **债务：** 卡片，左侧 3px 朱砂边。依次为：债权人、状态胶囊、「本金 X · 未偿本金 Y」、红色进度条（长度 = 未偿 ÷ 本金）、还款条件、到期日。
   - **资产：** 按「房产 / 车辆 / 其他资产」分组，组标题后面带数量。每项是一张卡片：绿色线稿图标、名称、估值（为空时显示「估值 未确认」，暗色）、状态胶囊、来源，车辆再加型号和车牌。
4. **空状态文案：** 「暂无收入记录 / 暂无债务记录 / 暂无记录」，原文不变。

## 三、历史时间轴

1. **视图切换：** 「重大纪事 / 史料记录 · N」用分段控件，保留 `aria-pressed`。
2. **搜索和年代：** 搜索框加「全部年代 ▾」按钮。点按钮从子抽屉选年代，选项和原下拉框一致。
3. **范围筛选**（新增）：「全部 / ■ 世界重大纪事 / ■ 主角重大纪事」胶囊，前面的色块同时充当图例。
4. **主轴：** 电脑端是三栏，手机上改成**单列**。
   - 左侧 3.4rem 为时间（等宽字，可以换行）；
   - 时间右边是一条金色竖线，每个时间组配一个空心金色圆点；
   - 同一时间组里，世界纪事在前，主角纪事在后，都排成一列；
   - 纪事卡左侧 3px 色边区分来源（世界为蓝，主角为朱砂），卡内依次为类别、标题、两行摘要；
   - 同组分页「‹ 1/2 · 共 N 条 ›」放在该组最后，不变。
5. **纪事详情：** 在抽屉里推入，标题栏换成「‹ 时间轴」。字段和电脑端一致：
   - 要素用两列 `dl`；
   - 历史纪事为衬线正文，首行缩进；
   - 主要经过用圆号列表；
   - 结果和影响带性质胶囊；
   - 来源信息放在底部虚线下方。
6. **史料记录：** 卡片里的列表，每条依次为标题、时间、摘要、认知标签。

## 四、物品栏

1. **分类：** 吸顶的胶囊横条，每个胶囊是图标、分类名、数量。保留 `aria-label`「X，N种物品」。
2. **摘要：** 摘要 `role="status"` 依次显示分类名（衬线）和「N 种物品」。
3. **物品格：** 三列物证标签，保留 `inventory-tile`。
   - 右上角一个穿孔，内容依次为：类别小字、1.9rem 线稿图标、名称（最多 2 行）、徽章、×N。
   - 已装备的卡片加浅金渐变；选中的卡片加 2px 金色描边和 `aria-pressed`。
4. **详情：** 点物品后，**从底部升起子抽屉**，物品格保持不动。
   - 顶部是「← 返回背包」（电脑端保留在 DOM、窄屏才显示的那个按钮，就在这里用上）。
   - 下面依次为：斜纹框里的图标、类别胶囊、名称、徽章；描述（左侧金线，衬线字）；`dl`（数量、单件参考价值或「待估价」、当前状态、`itemAttributes()`）。
   - 打开后焦点进入名称；关闭后焦点回到原来那张卡片。
5. **空状态：** 「背包里暂时没有物品。」/「此分类暂无物品。」

## 五、设置：仿手机系统设置

1. **分类列表：**
   - 顶部是副标题「本地偏好与 AI 渠道」。
   - 下面是一组列表行，每行依次为：朱砂方印（连 / 词 / 忆 / 运 / 管）、分类名、一行说明（新增）、有未保存修改时的朱砂小点、›。
   - 列表下方另起一组，放 `NoticeLinks`：「游玩须知与免责声明」「王朝公告」，样式为蓝色文字行。
   - 五个分类的说明文案：渠道、密钥与模型路由 / 叙事人称、风格与开关 / 即时记忆与记忆总结 / 阶段开关与超时 / 查看与编辑提示词。
2. **分类页：** 推入，标题栏换成「‹ 设置」。
   - **表单：** 一律上下排列，标签加粗，取值范围用小字跟在标签后面。
   - **输入框：** 字号 16px；数字输入框内显示单位后缀。
   - **开关：** 改成手机常见的胶囊开关，打开为绿色，放在分组卡片里，每个开关占一行。
3. **AI 连接：**
   - **渠道卡：** 可以横向滑动，每张卡占宽 72%。卡片依次显示名称、协议色胶囊、服务地址、默认模型；当前渠道加「当前渠道」角标；最后一张是虚线的「＋ 新增渠道」。
   - **编辑表单：** 放在一张卡片里。密钥框和模型框右侧各附一个按钮，分别是「显示」和「测试连接」。
   - **生成参数：** 折叠。
   - **删除渠道：** 赭红描边按钮，后面接原来的说明文字。
   - **模型路由：** 电脑端的表格在手机上改成**每个阶段一张卡片**。
     - 卡片头依次为圆号、阶段名，右侧是「跟随正文」小开关；正文生成这一张显示「—」。
     - 卡片下方是两个并排的下拉框：渠道和模型。
     - 跟随正文打开后，两个下拉框变暗，已选值保留。
     - 类名照样用 `.is-follow`。
4. **运行：** 阶段开关和超时设置的结构和电脑端相同。「校验与失败恢复（后续接入）」用虚线 `fieldset`，整体禁用。
5. **保存栏：** 固定在抽屉底部，包含安全区。
   - 左侧状态：已保存时显示绿点；有未保存修改时显示朱砂点加原有文案。
   - 右侧按钮：深墨底，文案按分类不变。
   - 提示词管理页没有保存栏。
6. **未保存拦截：** 在「AI 连接」或「记忆」页有未保存修改时，点「‹ 设置」或关闭会弹出一张卡片，浮在保存栏上方，左侧有 3px 朱砂边。卡片的标题、正文和「继续编辑 / 放弃本次修改」两个按钮，文案和逻辑都与现在一致。实现时继续用 `Dialog small`，样式改成档案纸。
7. **从首页打开：** 也用同一个档案纸全屏抽屉，不再用居中的弹窗。

## 验收

1. 在 375×667、390×844、430×932 下没有横向溢出；只有正文区滚动，吸顶条和保存栏位置正确。
2. **地图：** 在面包屑、区域块、下级地点、搜索结果、「定位到我」这五个入口里切换地点，视图和选中状态都能同步。多个根城市、成环、`parentId` 不存在等情况不能报错。
3. **经济：** 各种空值、已取消收入、本金为 null 的债务都能正常显示；两个合计会随数据实时更新。
4. **物品栏：** 子抽屉打开和关闭时，焦点处理正确，物品格的滚动位置保持不变。
5. **设置：** 分类切换、未保存拦截、保存成功和失败、表单校验，都与现在一致；密钥不出现在任何新增的展示里。
6. 现有 e2e 只调整选择器。
