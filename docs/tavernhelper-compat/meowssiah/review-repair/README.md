# C3 小猫之神独立复审整改记录

复审起点为 `2d89f09cdb7afb09c34fd829c17f91ad4a356803`，目标为 `release/1.0` 的 `ae55434d24d17de651cf94b46583387d6ac67efc`。本轮修改集中于五项反馈。测试使用 Node 24.19.0、锁文件依赖、Chromium 154.0.8037.57、桌面和 Pixel 7 模拟视口。所有渠道均为本机 Mock。下文的 POST 和 Token 数据均为合成试验观测。

## 五项复审结果

| 项目 | 整改及验证 |
| --- | --- |
| 跨版本存档兼容 | 旧构建严格解析 `saveControls`，先前会在其他标签写入 `oracleNote` 后报未知字段。新版用同库独立的 `oracleNotes` 仓库。版本升级事件独占迁移原开发版纸条，再删除控制记录中的这个字段。源记录有误或写入失败会中止整个升级。旧连接完成在途事务、关闭，刷新后读新库。新页面明确提示旧页面刷新。双端分别用真实旧发布构建和整改前 C3 构建写入、持有在途事务、升级、刷新，均保留存档、草稿与已有纸条。 |
| 实时阅读与失败诊断 | 之前四协议纯文本 SSE 要等 `session.read` 返回才出现正文。本轮将阅读预览、临时原文观察和完整交付分为三路。工具观察只提取已到达的顶层 `game_content`，经过长度限制和已有凭证脱敏。支持完整 JSON 转义，两个 UTF-16 代理单元跨片时等待下一个单元。未完成时单独标注，不交给续写或正式校验。正式沙箱完成、收据核对通过后，用正式正文替换预览。请求取消或失败不能保存这段工具正文。 |
| 内心话 | 保留原条目标识、位置、开关与认知边界。生成器将原作者的折叠 HTML 指令映射为叙述内的纯文本内心话。双端检查发送的要求、实际存入的内心话、刷新后的历史阅读，并验证模型意外返回的标签按文本处理。旧版本方案保留玩家自己的文字。显式保存旧发行默认值的条目采用新默认表现。文学资源版本随之变化，已冻结的旧断点仍执行原有版本保护。 |
| 单次直连及诊断 | 普通猫神继续只走一次直连。控制台解释可用渠道，浏览器报告直连网络异常时，提示列出网络、地址和跨域许可三种排查方向，并提示可能已受理或计费。两端拦截同一可中转地址的出站请求，普通模式直连一次加中转一次，猫神直连一次、中转零次。另外使用真实本机 HTTP 服务读完 POST 后返回无法跨域读取的响应，两端猫神各实收一次，纸条和正式状态保留。HTTP 错误、模型拒答、取消及玩家为旧断点选定的传输保留已有语义。 |
| 最近六条小纸条 | 逐档保留最近六条不同的已保存文本。回填只改变编辑框，保存才更新纸条，清除当前纸条与清空历史分设按钮。控制台说明纸条和历史不进入备份。保存选用的一次性纸条时，候选、世界观来源与按 ID 消费在同一事务完成。失败、并发替换和取消均保留相应内容。持续纸条和历史不会随消费删除。 |

存储入口见 `src/services/storage/oracleNotes.ts`、`saveRepository.ts`、`history/repository.ts` 及 `turnUndo.ts`。IndexedDB 从 10 升至 **12**。#259 开发分支使用 11。当前 GameState 格式仍为 **11**，备份格式仍为 **5**。纸条编辑受存档实例、时间线和记录版本约束。普通回合撤回保留本机纸条，删除、备份覆盖和历史恢复会清理被替换实例的数据。待确认期间修改纸条会使覆盖或恢复的旧确认失效。原旧二进制只能按其已有逻辑关闭连接。新版给出更新提示。

阅读入口见 `readLiteraryResponse.ts`、`literarySession.ts`、`toolObservation.ts`、`services/ai/runtime.ts` 与 `workflows/storyStage.ts`。OpenAI、DeepSeek、Anthropic 可以观测工具参数分片。Gemini 按其实际参数对象快照观测，仍须合法结束标记才能交付。明确来源的续写和经确认的旧断点均在这次生成准备时读取当前已保存的纸条。原来正文的来源和配置快照继续保留。原请求发出后再编辑纸条，只影响下一次请求。
