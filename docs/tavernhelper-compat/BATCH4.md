## 条目、保存和恢复

元数据来自控制台显式的分区及互斥列表，去除王朝固定关闭项。共 8 个分区、82 个可配置条目。人物与关系 9、局势与节奏 9、互动与视角 18、篇幅与文风 14、修辞与语言 10、附页与资料 2、自定义 4、亲密与形貌 16。「附页与资料」仅提供两项资料写作选项。程序管理的格式、标记、提示词搬运边界和附页不提供开关。[逐条 ID 及组规则](../../src/presets/resources/peinture-controls.json)

局势难度、推进速度、结尾问话、抢话、对话比重、转述、视角、心声、文风和亲密风格均允许最多一项。选「不指定」可以取消整组。四个自定义填写位置保留内置宏外壳，输入的花括号和双冒号按文字处理。旧版已改写外壳的覆盖以旧模板形式展示。

| 操作 | 生效位置 |
| --- | --- |
| 编辑与关闭 | 编辑副本只留面板。未保存关闭时需确认。 |
| 保存 | 先处理脚本待保存任务，核对读取时的旧覆盖，校验后一次写入全局预设键，并同步脚本持有的配置引用。写入失败保留编辑。 |
| 保存后再次生成 | 当前存档提供行动、人物和历史。请求开始时冻结本次配置。两个存档共用偏好。 |
| 恢复默认并保存 | 删除当前包的覆盖并重建运行时字段。涉及历史脚本启动覆盖时保留输入后刷新。渠道凭据、存档、其他游戏设置继续保留。 |
| 关闭或启用并刷新 | 沿用第三批刷新流程，阻止在飞切换，恢复未发送行动。恢复启动沿用 `?safe=1`。 |

四项采样沿用第一批的逐字段能力判断和明确拒绝后的兼容记忆。王朝保留渠道和输出上限，以及正文篇幅、选项、校验和存档事务。设置保存失败、预设初始化失败、预设响应处理异常、未还原工具、协议限制及上游错误有各自的错误入口。阶段诊断保留原始传输与包装器结果。预览仅在空闲存档下组装已保存的消息，本地 Token 规模估算不代表供应商 usage。[编辑器](../../src/ui/settings/PeintureSettings.tsx) · [保存接缝](../../src/presets/tavern/hostState.ts)
