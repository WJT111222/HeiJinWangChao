# 使用内置浪潮预设

1. 打开「设置 → 运行 → 正文预设」，选择「我即浪潮 · 1118 peinture」，点「保存预设并刷新」。如果已有其他待保存设置，先保存它们。
2. 打开「王朝预设设置」。游戏里也能从电脑正文工具栏或手机三阶段抽屉进入。可以先在「局势与节奏」调整推进速度，再点「保存调整」。这些偏好适用于本浏览器中的各存档，下一次主动生成时生效。
3. 使用平常的正文生成入口。「浪潮 · 状态」可查看脚本的实际工作状态。「兼容与预览」在已进入存档且空闲时提供已保存配置的本地估算。
4. 「恢复默认」后点「保存调整」，恢复内置王朝版的条目、采样和脚本偏好。要恢复王朝原生正文，回到「设置 → 运行」，选择「关闭」并保存刷新。脚本妨碍正常启动时，在网址的井号前加上查询参数 `?safe=1`，进入运行设置关闭预设。

预设接管正文文风、人称及相关写作偏好。游戏继续管理篇幅、行动选项、模型、渠道、超时和最大输出。关闭预设后原有写作偏好继续生效。预设只作用于正文，变量、世界及记忆使用游戏原有流程。

本版仅提供这一份内置预设。附页、HTML 卡片、预设和角色卡导入、酒馆渠道向导均未开放。
