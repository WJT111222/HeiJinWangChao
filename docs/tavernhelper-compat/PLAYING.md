# 使用内置浪潮预设

1. 打开「设置 → 运行 → 正文预设」，选择「我即浪潮 · 1124 anime」或「我即浪潮 · 1118 peinture」，点「保存预设并刷新」。如果已有其他待保存设置，先保存它们。
2. 打开「王朝预设设置」。游戏里也能从电脑正文工具栏或手机三阶段抽屉进入。可以先在「局势与节奏」调整推进速度，再点「保存调整」。这些偏好适用于本浏览器中的各存档，下一次主动生成时生效。
3. 使用平常的正文生成入口。「浪潮 · 状态」可查看脚本的实际工作状态。「兼容与预览」在已进入存档且空闲时提供已保存配置的本地估算。
4. 「恢复默认」后点「保存调整」，恢复内置王朝版的条目、采样和脚本偏好。要恢复王朝原生正文，回到「设置 → 运行」，选择「关闭」并保存刷新。脚本妨碍正常启动时，在网址的井号前加上查询参数 `?safe=1`，进入运行设置关闭预设。

文学预设接管正文文风、人称、篇幅与叙事节奏。在「设置 → 提示词」可打开当前预设控制台。游戏继续管理行动选项、模型、渠道、超时和最大输出 Token。关闭预设后原有写作偏好继续生效。预设只作用于正文，变量、世界及记忆使用游戏原有流程。

1124 在「我的方案」保存和交换文学条目，在「潮汐外观」选择日夜配色与浪潮标识。「主线时序」可以核对当前存档的正式时间。选择意识流时，控制台会选用第一人称与黑箱心声，并关闭纯对白。两版分别保存设置。[1124 适配和验收](1124/README.md)
