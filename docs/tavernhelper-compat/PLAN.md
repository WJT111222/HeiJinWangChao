# 阶段 B 建议与复审门禁

### 建议冻结的首期范围

来源组合为索引中的固定双版本。先在 Chromium 桌面/手机视口跑同一套原创差分夹具，随后对 WebKit 验证隔离、取消、视口和恢复；Firefox/真机未测前不声明支持。只测 OpenAI 兼容 Story 的 JSON、SSE 与可选单次工具输出；其他协议走原生模式，未来分别验收。B 实验台只使用合成资料、Mock 传输、内存仓库。所有数字是建议门限，需负责人批准。

| 项目 | 建议限制及超限处置 | 静态依据与如何校准 |
| --- | --- | --- |
| 包/脚本 | 4 MiB 原 JSON，最多 16 份脚本，单脚本 1 MiB，JSON 深度 32；激活前拒绝 | 样本 1,650,746 B、两脚本最大 591,492 B；边界、超一字节、嵌套和重复身份夹具 |
| 提示、正则 | 256 个条目、每项 256 KiB；32 条规则、单替换模板 64 KiB | 样本 164 项，最大 172,934 B；12 条规则最大替换 36,166 B。长文本和双绑定来源分别测，监控展开后体积 |
| 消息、流、变量 | 单桥消息 256 KiB，队列 1 MiB；单尝试每方向累计 8 MiB；每脚本设置/临时变量各 256 KiB，包内合计各 1 MiB。超限终止，禁用静默截断后提交 | 样本初始变量为空，不代表长期用量。main SSE buffer 上限 8,000,000 字符、观察记录有独立容量限制，不能混用字节/字符。测 UTF-8、多次复制、慢消费者、取消后回收。[G·sse.ts L20](https://github.com/WJT111222/HeiJinWangChao/blob/0bdffc9d39b231b9b69a83181d979525e104fca9/src/services/ai/sse.ts#L20) [G·stageResponses.ts L9](https://github.com/WJT111222/HeiJinWangChao/blob/0bdffc9d39b231b9b69a83181d979525e104fca9/src/services/ai/stageResponses.ts#L9) |

| 网络 | 模拟生成恰一次；导入、打开控制台、dry run、失败恢复、禁用为零次。远程字体、模块和其他外发为零 | 在脚本 realm 之外记录 Mock 和受控网络请求；与宿主计数核对 |

### 自写夹具与通过条件

| 编号 | 方法与观察点 | 阻断标准 |
| --- | --- | --- |
| B1 包与实例 | 无执行导入；单脚本、目录开关、重复 ID、按钮同名、热更；逐步记录创建、点击、卸载次数 | 未授权执行、重复启动、旧实例继续响应 |
| B2 同步、身份与权限 | 连续 getContext、getPreset、脚本树；修改副本和原生引用对照；同一 tick 写后读；切包切档 | 将同步读变 Promise、共享真实主窗口、跨域获得隐私资料或滥写其他脚本 |
| B3 事件差分 | 固定上下游各跑原创监听器；记录 first/on/once/last、异步完成、重入/throw、stop 与显式移除、分派期间卸载的顺序 | 顺序造成出站差异、用空函数冒充，或撤权后回调有效；可解释的上游 stop 差异须写兼容声明 |
| B4 准备与付费边界 | 比较事件/包装同时启用、深克隆、重复 dispatch、干跑与两份并发快照；验证最终请求字段、传输次数和路由 | wrapper 没命中真实链、必需字段缺失却回退成功、二次出站、后改配置污染在飞请求 |
| B5 工具 | 原创工具 shouldRegister=false/异步 true；同名、换实例、auto/禁用/指定、混合文本、多工具、错误参数 | 假报可用、越权卸载、隐藏第二次调用或执行写入型工具 |
| B6 控制台 | 原生对象编辑后分别检查 UI 刷新、保存回执、重开、下次实际消息；并发改预设与落盘失败；手机点击和关闭 | 看起来保存但实际发送旧值，干跑估算产生费用、缺宿主 UI 却显示成功 |
| B7 预设与显示 | 自写顺序覆盖、marker/注入深度、嵌套与未知宏；固定随机/时钟；发送与仅显示正则、捕获、转义、重绑定冲突 | 宏残留未经同意出站、显示替换污染候选、未知扩展自动执行 |
| B8 回滚、恢复 | 首轮内存仓库；覆盖切档、撤权、刷新、崩溃冷启动、双标签、晚到、重复完成、备份缺附属状态。D 再用正式 Repository 合成存档测 Undo/收藏恢复与幂等 | 半回合、错误时间线状态、自动重试、原生恢复仍启动旧脚本 |
| B9 传输与格式 | 同一内容 JSON/SSE，中文跨块、reasoning、usage 缺失/0/晚到；部分参数、供应商拒绝、读错、客户端停读、正常 EOF、重复 finish、脚本合成 Response/结束。四个层次逐一比对，Spy 检查候选/Commit | 把未知当零、最长文本胜出、真实结束但脚本添写事实、缺记忆仍通过、失败写入正式状态 |
| B10 隔离与资源 | 无凭证环境、外部观察网络，逐项验证 SAFETY 的通道；检查无权限请求、迟到与重放被拒，预算边界、超限、不可响应时由独立监督者停止，可信主页面仍可交互 | 无法证明封闭、主页面卡死、重启循环或暴露凭证。普通桌面视口不得冒充真机结果 |

**验收分母**：每个固定组合逐行列出 CONTRACTS 的适用接口和 B1–B10 的适用场景。公开夹具、私有主脚本、私有控制台、整包分别有结果与分母；跳过、回退和未授权场景单列。先通过自写夹具的功能、隐私、失控恢复测试，再经批准运行私有脚本。主脚本须观测一次真实经过包装的 Mock，控制台须证明一次持久配置对下次请求生效，整包须验宏、正则、扩展与输出契约。一个通过不能给另两个计分。

### 分批改动与协作

1. **B1–B3**：拟建实验目录内的包解析/清单、外部监督、实例管理、事件与镜像；先测隔离、同步及退出。暂不接入游戏入口。
2. **B4–B10**：实验目录内接 Mock 网络桥、虚拟酒馆生成、受控响应投影、专用控制台和原创双端夹具。完整上游留在离线对照环境。先给出静态、差分、原样运行和改写运行四类证据。
3. **C（另批）**：通过 B 后再提包管理/版本、权限与设置持久化、宏与正则子集实现。成本重点在复现上游对象/事件语义和撤权清理。第三方库逐项许可审核。
4. **D（另批）**：Story runtime 的装配/传输接缝、规范化、现有验证和诊断 UI；与 #192 协调只读世界书投影版本及预算。正式剧情变量持久化、主库/备份/回溯协议任何调整先单独审查。E 才讨论广泛兼容声明。
5. **B 前负责人决策**：批准路线、锁定版本与不搬运受限代码；私有样本允许运行的分支与许可；专用 UI/禁外网/禁主域的兼容损失；Mock 单协议、浏览器与数值预算；当 DOM 与强制终止不可兼得时接受“需适配/阻断”；批准各自验收分母与 #192 的接口边界。A 不授权进入生产存储、真实模型或发布。
