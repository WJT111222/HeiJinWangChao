# Beta 主世界书热补丁

入口在「设置 → 世界书」。两本内置书默认开启，可以分别查看全文、关闭或复制。复制会产生有独立书籍 ID、版本 ID 和常驻条目的玩家主世界书，初始为停用。恢复官方默认开关会开启两本内置书。玩家书的用途在详情中修改，和书名、条目一起保存为新版本。

## 哪些资料会发送

| 资料 | Story | Variables | World |
| --- | --- | --- | --- |
| 开启的官方世界观、社会生态 | 按原顺序装配 | 按原顺序装配 | 按原顺序装配 |
| 开启的玩家主书中启用的常驻条目 | 全文一次 | 同一份全文一次 | 同一份全文一次 |
| 玩家主书中的关键词条目 | 按现有引擎触发 | 无 | 无 |
| 普通世界书 | 按原有常驻、关键词、概率、分组、递归和深度规则 | 无 | 无 |

开局与普通回合共用上述规则。可同时启用多本主书，也可全部关闭。常驻资料按书籍 ID 排序，书内保留版本中的条目顺序。两本书采用相同文字时仍各有自己的条目身份。关闭一条或一本后，从下一次新生成流程生效。

官方正文仍由原资源和清单加载。开启文学预设时，只有启用的官方材料进入世界观占位符。玩家常驻资料使用独立的 user 消息 `MAIN_WORLDBOOK`，包含版本、哈希、条目 ID 和正文。资料经 JSON 序列化并转义尖括号。宏和脚本字符按原文发送，放置时机在文学预设脚本处理之后。Story 触发 Worker 只扫描主书该版本的非常驻条目，普通书沿用已有路径。补充资料容器的说明已改为按已启用的主书确定基础背景。

浮生身份、输出协议与排序边界继续由提示词清单校验。旧底座 `shared.00_world` 保持禁用。主书常驻条目不走关键词扫描的 Token 预算。真实请求检查器显示供应商协议序列化后的消息与估算，模型的实际使用量以响应为准。

## 书库与回合恢复

- 独立 IndexedDB `heijinwangchao-worldbooks` 从 V3 升至 V4。升级事务只新增 `mainSettings` 与 `turnWorldviews`。既有版本、启用记录、来源和内容哈希原样保留。老书没有用途字段时按普通书处理。Worker 可读取 V1–V4。旧页阻塞升级时，关闭旧页再重试。
- 原生导出含版本元数据 `metadata.purpose`，重新导入会核验哈希并恢复用途。酒馆书、角色卡、新建空白书默认普通。官方资源独立于本地安装记录，同名导入或副本可自由编辑。
- 官方开关按模块 ID 在独立事务中写入。玩家书编辑和删除沿用版本比较。书架收到其他页通知或重新获得焦点后重读数据库。旧详情有尚未保存的编辑时会提示冲突，保留文字供抄取。
- 首次正式 Story 在发出请求前捕获基础资料。绑定使用存档 ID、创建时间、回合 ID、基准修订及 Story 来源修订。保存候选后修订加一，Variables、World 据此读取同一份快照。书在生成中被停用、编辑或删除，已捕获的常驻资料仍完整可用。已删除旧版本中的关键词可能无法再次扫描，程序会记录跳过原因。
- 原流程失败重试、续写和页面刷新会复用绑定。重新 Roll 已选正文、成功结算后的新回合、失败后重新绑定行动会读取新配置。新流程启动时清理同存档已越过的旧回合和旧正文绑定。查看请求预览只读取快照。
- 正常存档、正式草稿、撤回点和备份不携带世界书开关或正文。跨浏览器迁移时，使用原生世界书导出与导入迁移玩家书，并在目标浏览器核对开关。旧草稿或异机恢复缺少原绑定时，若当前使用自定义组合，恢复入口会要求重新生成正文。仅有两本默认官方书时按 Beta 旧草稿规则继续。跨设备无法证明旧草稿当时使用的配置。
- 当前配置、所选版本或已有快照校验失败时，本次阶段在传输前返回错误。补回版本、修复配置或恢复书库访问后可重试。主动全部关闭时三阶段正常工作。

## 验证材料

- [默认与文学预设的 Mock HTTP 请求体](evidence/mock-http.json.gz)。解压得到 JSON 数组，`label` 标明回合、阶段和模式，`body` 为传输层收到的完整 JSON 字符串。收录只启用玩家主书时的开局和普通三阶段，以及文学预设重试、续写、下游恢复和重新 Roll，共 12 份。捕获不含请求头或密钥。矩阵断言覆盖全部八种组合。固定的 400 响应用于检查发出的请求，正式结算由另外的成功响应夹具验证。

## 题材边界与正式版合流

四座开局城市仍由 `src/domain/openingCity.ts` 和创角模型提供。人民币分及金额约束在 `src/domain/common.ts` 与经济领域，职业和组织字段由创角职业表及组织 Schema 定义。真实世界写作设置、信息传播提示、正式时钟和开局初始化分别保留在写作设置、`shared/02_knowledge`、`shared/03_time_events` 和命令协议中。替换世界观后，这些独立规则仍会出现。

本补丁基于 `main@55cdc6edf84dab533719dbcf6ef907b10058657a`。后续由正式版同步 main 时，应针对其当时的文学预设与脚本宿主复查最终传输边界、三阶段请求、数据库升级和草稿恢复。新预设若自行重建消息，须继续在最后的协议序列化边界插入玩家资料。
