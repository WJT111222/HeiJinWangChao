# 本回合变化 · 给 Codex

设计稿：`heijin-changes.html`，在主界面 v5 加三阶段工作流的基础上，加了「本回合变化」按钮。
- **查看方式：** 默认收起，点最新回合正文末尾的「本回合变化」按钮展开。也可以用链接 `#chg=1` 直接看展开后的样子。
- **示例数据：** 设计稿里列出的变化条目都是演示用的。

## 原则
- **不在别处加角标或高亮。** 人物、物品、面板列表里都不放「新」标记，只有一个按钮，玩家点了才展开。
- **只读。** 不改存档，不调用 AI，不影响结算和撤回。
- **只在最新的、已正式结算的回合上显示。** 草稿、预览、生成中的回合都不显示。

## 数据来源（不改存档）
- 变化来自**结算前状态**与**当前状态**的前端对比。
- 结算前状态取撤回恢复点：`turnUndo` 里最新一条快照的 `stateJSON`，它就是本回合开始前的完整 `GameState`。现有逻辑会保存最近 5 回合。
- 建议写成纯函数 `diffTurn(before: GameState, after: GameState) → ChangeGroup[]`，补单元测试，结果只在打开时计算一次。
- **拿不到结算前状态时**（开局第一回合、撤回记录因容量限制被跳过、恢复点不连续、旧存档）：
  - 按钮仍然显示，但置为 disabled，后面跟一行小字「本回合没有可对比的结算前记录」（新增文案）。
  - 也可以直接隐藏按钮，二选一，以第一种为准。

## 收起态：按钮
- **位置：** 最新回合稿纸内部，正文最后一段之后；上面有一条虚线分隔，下面接「接下来你想做什么」。
- **样式：** 胶囊按钮，从左到右依次是：
  - 「本回合变化」
  - 「N 项」（等宽字，金色）
  - 一排分类色点，有变化的分类才出现，`aria-hidden`
  - 圆形箭头 ▼，展开时转成朝上
- **属性：** `aria-expanded`，`aria-controls` 指向清单。
- **无变化时：** 按钮显示「本回合变化 · 无」，并置为 disabled。

## 展开态：变化清单
- **布局：** 两列分组卡片（1199px 及以下改为一列），用 `role="region"`，`aria-label="本回合变化"`。展开时淡入 0.22s。
- **分组卡：** 头部依次是分类色点、分类名、条数。

  | 分组 | 色值 |
  |---|---|
  | 时间与地点 | 蓝 `#8EC1E0` |
  | 主角 | 金 |
  | 人物 | 赭橙 `#D08A6A` |
  | 物品 | 冰蓝 `#A9C3D8` |
  | 世界 | 绿 `#7DBB9C` |
  | 记忆与历史 | 紫灰 `#9A8FC8` |

- **条目：** 每一条都是一个按钮，点击后打开对应的面板，并定位到那条记录。
  - **左侧：** 对象名，有字段时加字段名，比如「林晚 关系倾向」。
  - **右侧数值：** 等宽字，三种写法：
    - 数字：增加为绿、减少为赭红，比如「−28.00 元」「30 → 34」。
    - 时间：旧值用删除线，再接新值。
    - 状态标签：新增或获得为绿；删除、失去或移除为赭红；变更、离场、新阶段、状态迁移为金。
  - **第二行小字：** 「旧 → 新」的完整文本，或者新增对象的一句简介。
  - **悬停：** 右侧显示要跳转去的面板名。
- **底部小字：**「与本回合开始时相比 · 点任一行打开对应资料 · 不影响存档」（新增文案）。

## 对比哪些字段

| 分组 | 字段 | 显示方式 |
|---|---|---|
| 时间与地点 | `worldClock`、`protagonist.locationId`（显示地点名）、`weatherText`、`environmentText` | 时间写「旧 → 新」，后面加经过的时长；其余写「变更」，附上完整文本 |
| 主角 | 现金和线上资金（金额差值）、身体、情绪、社会状态、法律状态，以及 7 个装备槽 | 金额写差值，其余写「变更」 |
| 人物 | 新增人物；关系倾向；与主角关系的文字；在场或离场；位置；新增已知信息和记忆的条数 | 新人物写「新人物」；关系倾向写数值箭头 |
| 物品 | 新增、移除、数量变化、装备状态变化 | 「获得 / 失去」，数量写 ×N |
| 世界 | 事件和任务的新增、状态迁移、新阶段；组织的新增、关系变化；新增地点 | 状态迁移写「旧状态 → 新状态」 |
| 记忆与历史 | 新增的记忆（按层级汇总）、新增的历史纪事和史料记录 | 写「+N 条」，第二行写第一条的摘要 |

- **排除：** 内部字段一律不进清单，包括 ID、revision、时间戳之类的元数据，以及 `knownToProtagonist` 这类不该透露的世界内部信息。
- **可见性口径：** 和各面板对玩家的显示口径保持一致，面板里看不到的，清单里也不出现。
- **条目太多时：** 单组超过 8 条，先显示前 8 条，后面接「还有 N 条」，点击后展开剩余部分。

## 验收要点
1. 只在最新的已结算回合显示。发送新行动后，按钮跟着移到新回合；撤回之后，按钮显示的是撤回后那个最新回合的变化。
2. 拿不到结算前状态、或者本回合没有任何变化时，都按上面的规则显示。
3. 每条变化都能跳到对应的面板和记录。
4. 不会展示面板里本来就看不到的信息。
5. 1440×900 和 1280×800 下不溢出；展开和收起可以用键盘操作；reduced-motion 下没有动画。
