## 页面与保存方式

| 分区 | 页面 | 保存行为 |
|---|---|---|
| 模型与连接 | 渠道与密钥、模型分配 | 同一份渠道、密钥和模型草稿，两页共享保存、放弃和离开保护 |
| 模型与连接 | 跨域与网络 | 浏览器中转开关立即保存 |
| 写作 | 正文与风格、提示词开关 | 保存本地设置 |
| 写作 | 文学预设 | 原预设选择和脚本宿主，保存预设并刷新 |
| 世界 | 世界书 | 原世界书编辑、绑定与保存 |
| 回合流程 | 生成阶段、超时与重试 | 保存本地设置 |
| 回合流程 | 记忆 | 原记忆设置保存与总结入口 |
| 扩展功能 | 手机、小剧场 | 保存本地设置 |
| 扩展功能 | 文生图 | 原文生图配置、跨标签合并与密钥保存 |
| 外观与提醒 | 外观与提示音 | 选择后立即生效 |
| 数据与排查 | 变量管理、提示词管理、反馈建议 | 沿用各自的修订、保存与提交入口 |

本地设置草稿按页标红点，点击「保存本地设置」提交整份草稿的修改。手机经分类目录切换同组页面也会保留编辑。关闭面板、离开独立设置或跨组时会提示；本地偏好允许玩家明确保留草稿后查看其他页面。打开已保存的原生、小猫之神和浪潮模式仍使用原有预设入口。

## 模型选择和出站请求

| 用途 | 默认解析顺序 | 实际请求 |
|---|---|---|
| 私聊 | 私聊 → 主角与现场 → 正文 | 原手机阶段 |
| 群聊、小黑书 | 各自用途 → 私聊 → 主角与现场 → 正文 | 原手机阶段，使用相同的结构化输出和直连规则 |
| 小剧场 | 小剧场 → 正文 | 原小剧场阶段，每篇仍可覆盖默认模型 |
| 生图提示词 | 生图提示词 → 主角与现场 → 正文 | 四协议 AI 客户端，直连、非流式、文本输出 |

`configuration.ts` 统一定义各用途允许的跟随目标。`requestSnapshot` 的可选 `route` 只决定渠道与模型，`stage` 继续决定处理方式。改回跟随会记住之前的独立选择，删除渠道会清理对应引用。正文使用的渠道被删时须重新选择。浏览页面、试配路由和恢复默认跟随不会生成内容。

## 旧配置和存档

- 读取旧 `heijin.ai.v1` 时在内存中补齐四条默认路由，保留原渠道、模型和独立选择。只有显式保存时才写回。渠道凭证沿用既有密钥库，保留会话或本地持久化方式。
- `heijin.settings.v1` 的 `phone` 和 `theater` 均可缺省。群聊默认不限，贷款提前三天提醒，零天表示到期才提醒。小剧场默认中篇、跟随主线人称。新建单篇时修改目标字数或人称，只影响当篇。
- 群聊完成原调度后按返回顺序处理，只计算 `reply`。超出上限的成员记为 `unread`，不发逐人回复请求。建群与邀请沿用逐人处理。
- 旧文生图配置的 `textBase`、`textModel` 和凭证库的 `text` 条目保留。原先单独填写的文本服务须在「渠道与密钥」建渠道并分给「生图提示词」。检测到旧模型时展示一次迁移说明，点击「知道了」只写本机确认标记。
- 四种图片生成后端和五个转换模板保持原存储与用途。新的文本转换使用统一渠道，保留去思考段、词组清理、八千字上限、空输出及凭证回显丢弃。
- 本次未修改正式存档格式、提示词原文、命令注册表、供应商协议解析器或跨域回退的传输实现。
