# 设置重新分区整改与复审交接

本轮复现基准为 `1974ab6e14f63fb48e440477022c02fe42a3b7f7`，发布对照为 `0096bdf191ae2303d79adf62b2648a4cf250c358`。整改沿用 #262 的开发分支。下列证据使用 Node 24、锁定依赖、合成存档和 Chromium 的 Mock 接口。手机结果来自浏览器设备模拟。

## 配置及凭证保存

渠道与密钥、模型分配共用草稿。保存时以打开编辑器的基准、本页修改和刚读取的持久配置做三方比较。渠道按稳定 ID 合并，同一渠道按字段合并，参数列表按整项处理。每个任务的渠道、模型及跟随方式作为一个相互依赖的选择。删除与同时编辑、失效的渠道引用、密钥与服务地址的冲突均会保留输入并提示玩家。玩家可继续编辑，或明确放弃并载入最新配置。

只写本页明确改动的凭证和已删除渠道的凭证。凭证仍由原 CredentialVault 分别保存在会话或持久存储。保存前读取两个位置的快照。若写入失败，恢复原值及其位置。若恢复也受浏览器阻止，显示涉及的渠道，并为重试记录本页写入后可核实的残留状态。比较及错误提示均无需公开密钥。

浏览器可在另一个渲染进程取得 Web Lock 后继续读到旧的 localStorage 视图。两个标签各做 100 次读改写，单用 Web Lock 的诊断运行实际只观察到 159 次累加。现在独立的 IndexedDB 读写事务串行处理保存，并核对上一笔保存最后写入 localStorage 的随机标记。落后的一方会等待本标签实际看到该标记，再读取配置和凭证。索引库只记录同步标记及时间。正式存档和密钥的存放位置沿用原约定。相同压力探针得到 200 次累加，双端回归还验证了保存冲突、显式放弃、同步标记写失败的回滚与重试。若浏览器阻止协调存储或长期看不到上一笔标记，页面会报告保存失败并保留编辑。

## 设置反例

| 项目 | 实现及实际复跑 |
|---|---|
| 两标签编辑 | A 修改渠道、正文模型及持久密钥。B 留在 AI 页，或先离开再返回，只改另一渠道。两种操作下 A 与 B 的值均保留，模型 POST 均为 0。并发删除、远端新增路由、相同或不同的凭证修改另有单测。 |
| 转换材料 | 图片词组转换沿用统一模型路由并关闭全局请求检查记录。存档 A 的图片任务正常完成，文本和图片接口各收到一次 POST。切至存档 B 的连接测试列表无法看到 A 的材料。四种协议分别验证普通返回、文本密钥或图片密钥出现在返回中时拒绝接收，以及主动取消。 |
| 未保存编辑 | 图片密钥或记住状态计入文生图页修改标记。离开时可继续编辑或明确放弃。提示词排序计入分类红点和离开确认，同组切页或选择保留草稿后可返回继续排序。排序依原按钮独立保存。 |
| 小剧场默认篇幅 | 从自定义切回固定档时只移除无效的隐藏字数，有效自定义字数仍可回用。桌面及手机分别用空值和 99 切换短篇并保存，四次均写入 short，模型 POST 为 0。 |
| 窄桌面模型名 | 在设置内容宽度不足时，模型控件占用完整一行。901 像素游戏内日夜实测，选择框从 55.22 增至 164.02 像素，模型名 fixture 的 58 像素文字可完整显示。 |
| 旧模型迁移提示 | 同源另一标签确认后当前页随存储事件同步。重新打开仍为已确认，原独立文本模型、地址与密钥均保留。 |
| 变量管理入口 | 没有活动存档时，首页日常设置不提供该入口。游戏内仍能从十七页导航进入并保存变量。 |
| 浏览器断言 | 按新分区进入渠道、路由、超时及记忆等页面。风格说明定位到剧情风格组。动画验收等待入场动画完成，减少动态效果的用例显式设置该设备偏好。保留原业务检查、几何阈值、请求数及显式保存断言。 |
