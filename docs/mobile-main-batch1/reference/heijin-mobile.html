手机端 · 主界面

用手机打开本文件会自动全屏。桌面上可以直接在机身里点按、滑动、下拉。

  1. 沉浸阅读：正文铺满全屏，城市夜景透出；往下读，顶部城市胶囊自动收窄。
  2. 拇指区：行动建议、输入、发送、导航都在下半屏。
  3. 横滑行动卡：左右滑选，点一下填入输入框。
  4. 底部抽屉：状态、世界资料、各面板、三阶段都从下方滑出，抓住把手下拉即可关闭。
  5. 点顶部胶囊：展开此时此地与主角状态。
