# 手机端 · 游戏主界面 交接文档

设计稿：`heijin-mobile.html`。用手机打开会自动全屏；在电脑上会显示在一个 390×844 的机身里，右侧是演示控制。

可以用 hash 直接打开某个状态：

- `#open=status`：状态抽屉
- `#open=world`：世界资料
- `#open=npc`、`#open=npc&p=0`：NPC 面板及人物详情
- `#open=wf&flow=error`：三阶段，失败状态
- `#city=sh|hrb|gz`：切换城市
- `#top=1`：滚到正文顶部
- `#acts=1`：滚到行动建议

## 原则

- **只改 ≤900px**，也就是 `compactSidebars` 为真时。电脑端不动。
- **功能和数据都不变。** 不改存档 Schema，不改 AI 格式，不改状态流转。只换布局和外观。
- 设计稿里的人物、文案都是演示数据。实现时一律用真实 state 的字段，缺失时用现有的「未记录」类占位。

## 整体结构（从上到下）

| 层 | 现在 | 改为 |
|---|---|---|
| 背景 | 纯色 | 复用电脑端氛围层：城市色、时段、天气、天际线（`src/ui/home/skyline.ts`）。手机上天际线只占底部约 34%，上面加一层渐变压暗，保证正文可读 |
| 顶部 | 56px 应用顶栏 + 两个可折叠侧栏 | **城市胶囊**（见下）。两个侧栏从正文列里移除，内容挪进「状态抽屉」和「世界资料」 |
| 中部 | 故事列 | 全屏沉浸阅读，左右各 20px 留白 |
| 底部 | 输入框 + `nav.mobile-game-nav` | **行动台**：三阶段细条 + 胶囊输入框 + 印章式导航，固定在拇指区 |

现有顶栏在手机上只露出 `.mobile-menu-toggle`（☰，`aria-label="打开游戏菜单"`）。它改为放在城市胶囊右侧的圆形按钮（2.75rem），胶囊相应变窄；点开后的「游戏菜单」（游戏首页 / 切换存档 / 设置 / 版本号）改为底部操作表，见 `MOBILE_MISC_HANDOFF.md` 第 4 节和 `heijin-mobile-misc.html#menu`。

## 1. 城市胶囊 `.top .pill`

- **内容：** 城市印章（渝/沪/冰/穗，用城市色）、地点路径（小字）、地点名、时间（等宽金色）、天气字。
- **收窄：** 往下滚超过 60px 时加 `.mini`，隐藏路径小字，高度变小；往上滚时恢复。
- **点击：** 打开「状态抽屉」。
- **天气字：** 用和电脑端相同的关键词映射（雨 / 雪 / 雾 / 阴 / 晴），`aria-label` 写完整天气。

## 2. 正文

- **正文字体：** 衬线，`1.04rem / 行高 1.98`，两端对齐。
- **剧本台词（手机版）：** 和电脑端的三栏不同，手机上改成两行：
  - 第一行：小圆头像 + 名字（`.hd`）。
  - 第二行：台词，左缩进，左边一条细线（`.say`）。
  - 主角那条线是 2px 金线，并带淡金底色（`.dlg.me`）。
  - 台词两侧照旧用「」。
- **回目铭牌：**
  - 直接复用电脑端四城铭牌的 CSS 和 `plate()`，整体缩到 `scale(.78)`；之前的回合缩到 `.66`，并整回合降到 `opacity .6`。
  - 副标题拆成两行：第一行是「日期 · 星期 · 时刻」，第二行（`.l2`，较暗）是「城市 · 地点」。这样窄屏上不会把地名从中间断开。
  - 数据来源和电脑端一样，用 `scene`；旧回合显示「时间地点未记录」。
- **本回合变化：** 复用 `CHANGES_HANDOFF.md` 的按钮。手机上占满一行，右侧是分组色点；点开后用底部抽屉展示分组 diff。

## 3. 行动建议：横滑卡片

- **布局：** `.rail-cards` 用 `scroll-snap-type:x mandatory`，每张卡宽 76%，露出下一张的边，暗示可以滑动。
- **页码：** 标题右侧显示「1 / 4」，下方是圆点页码，随滚动更新。
- **点击：** 把卡片内容填入输入框，并给卡片加选中金边。保持现有「点建议 → 填入输入框」的行为，不自动发送。
- **触感：** 支持 `navigator.vibrate` 的设备轻震 8ms，不支持就跳过。

## 4. 行动台 `.dock`

- **三阶段细条 `.wf-line`：** 三段 3px 的进度条，状态和桌面端工作流一致：
  - 已完成：金色
  - 进行中：流光动画
  - 失败：朱红

  右侧是一句状态文字和「详情 ›」，点击打开「三阶段抽屉」。
- **输入框：**
  - 胶囊外形，`textarea` 自动增高，最多约 5 行。
  - 字号必须是 16px，避免 iOS 聚焦时自动缩放。
  - placeholder 保持「填写你的行动」。
  - 左侧圆钮放现有的次要操作（设计稿里是「撤」= 撤回上一回合，弹出电脑端已有的撤回确认小弹窗）。如果现有操作不止一个，把这个钮改成「⋯」，点开小菜单。
  - 发送钮是金色圆钮，没有内容时禁用。
- **底部导航：** 沿用现有的四项，`aria-current` 逻辑不变，只换样式：
  - 故事：回到正文
  - 人物：现在打开人物档案。设计稿改为先开「状态抽屉」，抽屉里有「人物档案」入口；如果想保持原行为，直接开人物档案也可以
  - 世界资料：打开「世界资料」抽屉
  - 设置：打开设置

  每项是一个小印章，当前项实心金色。
- **背景：** 从透明渐变到实色 `#08090a`，正文不会从导航后面透出来。
- **安全区：** 底部留出 `env(safe-area-inset-bottom)`。

## 5. 底部抽屉（替代现有全屏 Dialog）

**做法：** 不新写组件，给现有 `Dialog` 加一个手机变体（例如 `variant="sheet"`）。焦点陷阱、Esc 关闭、`aria-modal`、`aria-labelledby` 都照旧。

**样式：**

- 从底部滑入，`translateY` 过渡 .36s。
- 圆角 22px，顶部有抓手。
- 最大高度是屏幕高度减去顶部安全区再减 18px。
- 面板类抽屉加 `.full`，直接拉满到这个高度。
- 遮罩是 55% 的黑色，点击遮罩关闭。

**下拉关闭：**

- 在抓手或标题栏上按住下拉；内容区已经滚到顶部时，在内容区下拉也可以。
- 超过 110px 就关闭，不到就回弹。
- 用 pointer 事件实现，见设计稿里的那段 IIFE。
- 内容区设置 `overscroll-behavior: contain`，避免滚动穿透到正文。

**打开时的焦点：** 落在抽屉容器上（`tabindex=-1`，不显示描边），不要落在关闭钮上。否则手机上一打开就会看到一圈金色焦点环。

### 5.1 状态抽屉（深色）

承接原来两个侧栏的内容，字段全部来自现有 state：

- **此时此地卡：** 地点路径、地点名、大号时间、日期和星期、时段、天气、环境。卡片底色带城市色。
- **主角：**
  - 头部是印章、姓名、年龄、性别、职业。
  - 现金（金色）和线上资金分两格。
  - 身体和情绪两张小卡，左边是城市色竖线。
  - 下面是装备清单：上衣、下装、鞋子、饰品、主武器、副武器、载具。值为空时显示灰色「无」。
- **底部：** 两个入口按钮，「人物档案」和「经济与资产」。点击后打开对应的档案纸抽屉。

### 5.2 世界资料抽屉（深色）

- **布局：** 七个面板做成印章网格，一行 4 个：人 NPC、势 势力组织、图 地图、物 物品栏、事 世界事件、史 历史时间轴、忆 记忆。
- **角标：** 某个面板本回合有变化时，印章右上角显示数量。数量从「本回合变化」的分组结果里取，没有就不显示。
- **底部文案：** 保留现有的「从身边的人，到更远的城市。」
- **点击：** 先关掉本抽屉，再打开对应面板抽屉（间隔约 260ms，让动画衔接）。

### 5.3 面板抽屉（档案纸）

- **配色：** 用 `PANELS_HANDOFF.md` 里的档案纸色板和全部组件。抽屉本身就是一张纸（`.bs.paper`），印章变成朱砂实心。
- **列表 → 详情：** 手机上不分栏。点列表项后，在同一个抽屉里滑入详情，左上角是「‹ 人物名录」返回；打开详情时把内容区滚回顶部。
- **详情页分段导航：** 段落导航（人物档案 / 联系与地点 / 特殊资料 / 已知信息 / 记忆）做成可横滑的吸顶标签，点击时跳到对应锚点。
- **搜索与筛选：** 搜索框字号 16px；筛选 chips 可以横滑。
- **其余六个面板：** 按同样的模式套用：列表 → 同一抽屉内滑入详情。设置也用档案纸全屏抽屉。

### 5.4 三阶段抽屉（深色）

- **内容：** 和 `WORKFLOW_HANDOFF.md` 的展开态完全一致，只是从 popover 换成竖向时间线：
  - 失败提示
  - 「继续未完成阶段」主按钮
  - 三个阶段，每个阶段带「启用」开关和各自的操作按钮
  - 「查看变量候选（未结算）」
  - 重试与变更详情、本回合已绑定输入（只读）
  - 底部费用提示「生成可能产生第三方 API 费用。」
- **样式：** 开关改成手机常见的胶囊开关，但仍然是 `<input type="checkbox">`。

## 6. 细节清单

- **viewport：** `<meta name="viewport" content="width=device-width, initial-scale=1, viewport-fit=cover">`，外层高度用 `100dvh`。
- **安全区：** 顶部 `env(safe-area-inset-top)`，底部 `env(safe-area-inset-bottom)`。
- **软键盘：** 弹出时，行动台应该贴在键盘上方。如果现有布局在 iOS 上被顶飞，用 `visualViewport` 的 resize 事件，把键盘高度写进一个 CSS 变量给 dock 当 `bottom`。设计稿没有模拟这一点。
- **点按：** 所有可点元素至少 40px 高，加 `touch-action: manipulation`，按下时有 `scale(.97)` 反馈。
- **减少动态效果：** `prefers-reduced-motion` 时关闭雨、流光和滑入动画。
- **语义：** 抽屉内容不要用 `<h1>`；人物列表和网格项都是 `<button>`，有 `aria-label`。

## 建议实现顺序

1. 底部抽屉（`Dialog` 手机变体）和下拉关闭
2. 行动台：输入框、导航、三阶段细条
3. 城市胶囊和状态抽屉，同时移除两个侧栏
4. 正文：台词两行版、回目缩放、横滑行动卡
5. 世界资料网格，以及 7 个面板的档案纸抽屉，加上设置
6. 氛围层接入
