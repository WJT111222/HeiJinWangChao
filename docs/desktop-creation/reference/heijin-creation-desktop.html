思路：左边立档，右边填写

  • 左边是一份人物档案（档案纸，和电脑端世界资料面板同一套纸张语言），你在右边填什么，它就实时写上什么。每完成一步盖一枚红章；选好城市后档案顶边换成城市色，并盖上城市印（渝 / 沪 / 冰 / 穗）。
  • 右边是分步表单：顶部五个站点可以直接点，底部固定“上一步 / 下一步”，整页不滚动，只有表单区域在需要时滚动。
  • 最后一步点“确认并创建存档”时，档案上盖下“立档”大印，然后进入保存与自动开局。

每一步怎么用宽屏

  • 基本信息：姓名 / 年龄 / 性别一行；外貌与性格并排，模板做成可预览的小卡（显示前两行描述），选中后填入下方文本框，仍可自由改写。
  • 职业与能力：三栏浏览——左分类（5 类 + 自由选择）、中职业（显示技能摘要）、右详情（介绍、内置技能、长期影响）。下方保留“个人技能与专长”。自由选择时右侧换成四个自定义字段。
  • 城市与背景：四城大卡，用城市色、天际线剪影、城市印和经度；选中盖“起点”。背景文本框与“跳过背景”在下方。
  • 初始同伴：一张开关卡；打开后 8 个字段四列排布。
  • 确认与开局：四块复核卡并排，每块都能“修改”跳回对应步骤；“完整职业表单”保留在折叠里；开局偏好与费用提醒放在最后。

没有少的东西

  • 所有字段、模板、30 种职业、4 座城市、跳过背景 / 跳过同伴、开局包（我的开局包 / 保存为开局包）、开局时间说明、费用提醒、校验提示、“填写内容自动保留”都保留，文案不变。
  • 顶部演示条可切换：校验错误（第 1 步未填姓名）、保存中、保存失败。

只改电脑端

  • ≥901px 生效；手机端的“人生车票”保持不变。数据、校验、建档与开局授权流程不改。
