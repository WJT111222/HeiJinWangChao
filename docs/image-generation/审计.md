# 文生图迁移审计

王朝分支以 f6ca1ca8e961652ea8cdb8a490e3e8d653cd0482 为起点。参考源为 WJT111222/MoRanJiangHu 的 1.0.698（74aa92722b1ea1304210393679328aed07476972）。同目录 upstream.tsv 列出专项目录、相关测试、代理及直接依赖，路径均相对于该提交。

| 分类 | 源码及依赖 | 迁移决定 |
|---|---|---|
| 可直接提取 | imageTasks 的带权重词组拆分、去重、结构化词组清洗，comfyWorkflowTools 的节点识别与占位符，imageSizeOptions 的尺寸表 | 保留通用算法，排除武侠、私密部位和作者专用词组 |
| 需要适配 | image/index 与 runtime 是转导出，实际请求、格式识别、轮询和 ZIP 解析在 imageTasks；openaiImageTest、imageGenerationDiagnostics、apiConfig、imageGenerationRetry 涉及代理、原生机壳、日志和重试 | 按后端组装请求，使用浏览器直连、可取消读取、单图上限及王朝凭证库。付费提交仅一次，轮询只查询当前任务 |
| 需要适配 | dbService、imageAssets、玩家/NPC/场景 hooks、itemImageGeneration 及 npcImageStateWorkflow 依赖原项目存档和角色表 | 使用正式存档身份、独立 IndexedDB 仓库和王朝结算后回调。使用当前用途与稳定 ID 选择资源 |
| 重新设计 | ImageGenerationSettings、桌面和移动 ImageManagerModal、manualImageActionsWorkflow、imagePresetWorkflow、sceneImageArchiveWorkflow | 设置二级页、档案内操作、相册收藏与地点图片沿用王朝现有控件 |
| 排除 | 秘档专用、PNG 画风反推、图床、Capacitor、本机代理、CNB、同步、拍卖行、贡献图片及模型素材 | 无外部图片托管、作者部署服务、模型文件或上游预设素材随包分发 |

王朝 V7 已有 theaterIndex、剧场正文及独立版本标记。备份 V2 区分缺失剧场集合和空集合。图片升级沿用同一个数据库的 versionchange 及导入确认事务。历史时间线快照只保存主线进度。生图引用仅在界面与附属资源层计算。
