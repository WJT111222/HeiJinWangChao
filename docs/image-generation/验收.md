## 验证范围

协议测试以本地 Mock 响应驱动真实客户端。OpenAI 测试从生成接口取得 URL，再匿名下载位图；NovelAI 解压 deflate ZIP；ComfyUI 按 prompt_id 读 history 再通过 view 取图；SD WebUI 解码 images 中的 Base64。分别核对提交次数和后端字段。转化器开启时验证先文本后图片各一次，关闭时只提交图片，文本失败后停止。超时、跨标签关闭、重复通知均核对请求次数。

存档测试使用仓库实际读写代码和独立 IndexedDB 测试实例，覆盖相同人物名与不同存档 ID、图库版本并发覆盖、旧备份、带图和轻量备份、删除回收、配额失败的事务回滚。正式撤回和历史节点恢复测试保留原插画并核对历史关联。主角、NPC、地点、重要物品和车辆的资料投影使用各自的生成入口。

浏览器用例实际操作人物档案、上传、图片用途、锚点、正文插画、设置和人生相册，使用同源的两个标签页。独立联动用例让图片请求保持等待，同时验证主线 Story、Variables、World 各调用一次，完成结算并回到可输入状态。随后在第二标签页关闭功能并检查生图提交次数。关闭时另运行正式版既有的开局与下一行动纯文字回归。
