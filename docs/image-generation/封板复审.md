# 文生图 V1 封板复审

本轮基于 Draft PR #248 的展示与家庭兼容提交 `6d7a65d31f8dbcf45c1a051bde44b480194741b3`。交付范围为跨标签页配置与自动任务一致性、IndexedDB V8 打开与升级。图片用途、模型协议和正式回合结算继续采用该基线的实现。[展示位置、家庭接入与上一轮截图](展示与家庭兼容.md)

## 设置与任务

- `src/services/images/config.ts` 保留原有 localStorage 键。同源独立的 IndexedDB 偏好库 `heijin.image-preferences` 只存一条设置记录。首次保存沿用旧 localStorage 设置，之后每次使用同一个读写事务读取已提交值、逐字段合并并写回。每次变更有独立的配置版本号。显示缓存随事务更新，发布失败会回滚本次写入，重新进入页面会核对缓存。即使两个 Chromium 渲染进程暂时看见不同的 localStorage 值，也以事务记录为准。不同后端的参数、转换模板和四个自动规则分别合并。预设列表和画风列表各作为一个有序字段处理，允许明确保留排序和删除操作。
- `src/ui/images/ImageSettings.tsx` 在其他页面保存时更新未编辑字段，保留本页草稿。同字段出现两个不同的新值时显示双方值的预览，玩家逐项选择，再保存。发生在点击保存与读写事务开始之间的冲突也会返回编辑器。总开关即时保存，单独切换它时仍保留本页其他编辑。
- `src/services/images/queue.ts` 在入队时记录自动任务的来源规则。普通与特殊 NPC 分别对应各自的头像开关，剧情使用插画开关，重要物品与车辆使用原有的物品开关。设置内的关停计数与开关值一起提交。任务入队、取得全局执行锁和请求提交前读取已保存记录复查，标签页挂起期间错过「关闭、再次开启」两个事件的旧任务也会取消。
- 取得执行锁并通过复查即开始执行。关闭自动子开关会停止该规则的等待任务，已开始的任务继续，仍可手动取消。手动生成与其他规则独立，修改画风或模型允许原任务继续。总开关覆盖运行中及等待中的任务。旧配置缺少关停计数时从零开始读取。

## 数据库

`src/services/storage/saveRepository.ts` 在升级事务内调用 `src/services/images/library.ts` 的图片结构检查。合法升级会补齐缺失的仓库和索引，正常打开只校验结构元数据。检查覆盖四个仓库的主键与自增属性、两个 `saveId` 索引，以及 `imageJobs.subject` 复合索引的字段顺序、唯一性和多值属性。

同版 V8 结构损坏时，打开操作以 `STORAGE_SCHEMA` 结束并释放连接。`src/app/App.tsx` 将具体仓库或索引显示在原有存储错误区域。V7 升级遇到不兼容的已有主键时，升级事务回滚。旧页面阻塞升级时返回 `STORAGE_BLOCKED`，关闭旧标签后可重试。新版连接收到 `versionchange` 后仍自动关闭。

`release/1.0` 的核对提交 `f6ca1ca8e961652ea8cdb8a490e3e8d653cd0482` 使用 V7，#248 继续使用 V8。若实际 V8 已缺仓或缺索引，刷新后错误仍在，应保留原站点数据，等待正式版协调后的升级事务修复。已有有效备份的玩家也可在独立浏览器配置中恢复备份并继续游戏，原配置中的数据保留。合流时请核对同期存储专项的版本号和升级顺序。使用旧构建的标签页应在升级后刷新，以便所有写入者都遵循新的配置合并协议。配置读写使用 IndexedDB。图片生成继续使用 HTTPS 或 localhost 安全上下文中的 Web Locks。

## 回归证据

- `src/tests/image-storage-upgrade.test.ts` 覆盖新库、正常或含部分图片结构的 V7、完整 V8、同版分别缺失四仓或必要索引、错误主键及索引、升级阻塞与失败回滚。夹具逐仓比对存档、草稿、撤回记录、提交回执、小剧场、历史节点及已有图片字节，另以测试数据库的后续升级检测连接泄漏。
- `src/tests/image-generation.test.ts` 新增同字段过期提交、显示缓存滞后、写满回滚与四种自动规则错过关停通知的回归。`e2e/image-finalization.spec.ts` 使用同一浏览器上下文的两个页面实际编辑配置，核对不同字段并发提交、逐项冲突选择和草稿保留，并在本地 Mock 图片请求挂起时观察队列。异常 V8 的首页提示与原记录另用 Chromium 原生 IndexedDB 验证。
- `src/tests/unreadable-saves.test.ts` 的建库夹具改用升级事务。既有的 `e2e/automatic-settlement.spec.ts`、`e2e/image-generation.spec.ts`、`e2e/image-placements.spec.ts` 及图片单测夹具等待配置保存完成。
