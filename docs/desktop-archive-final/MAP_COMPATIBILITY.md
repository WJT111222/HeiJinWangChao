# 地点层级兼容性与只读性

## 正式数据边界

最新 main 的 LocationSchema 只有 `id`、`name`、可选 `parentId`。本批未修改 Schema、Repository、迁移、地点写入和主角当前位置。没有经纬度、城市推断、距离、方向、移动时间、寻路或移动按钮。

- 父子关系只按正式 ID 连接；海外根和跨城父级原样保留，不依名称推测行政区划。
- 根节点在卡片中称为「层级根地点」，避免把特殊根错误称为城市。
- 展示防环只断开内存投影的一条边，保留 WorldRecord 中原始 parentId。缺失父级的显示输入作为独立根并提示。
- **正式 GameState 当前本就拒绝缺失父级和循环。** 本批未放宽它，也不承诺这些非法记录现在能作为正式存档载入。异常测试直接覆盖 UI 投影，并同时断言正式 Schema 继续拒绝。合法旧档读取路径不变。
- 树使用原集合顺序；默认展开正式当前地点的祖先链，选中、展开、搜索与显示批次只缓存在 React 中。
- 左侧分支首次展示 50 条，示意区每级首次 20 条；提供继续显示。大量人物／事件／资产摘要超过 20 条时复用 RecordList。
- 选中地点、树、示意图图钉、面包屑和下级按钮共享选择状态；跨 NPC／事件返回恢复原地点。

## 汇总口径

| 展示 | 数据来源／边界 |
| --- | --- |
| 当前地点与祖先标识 | 正式 protagonist.locationId 沿 parentId 投影 |
| 此地人物 | NPC.locationId 与选中地点严格相等；不从名字关联 |
| 常驻于此 | 正式 usualLocations；保留角色与「主角已知／未确认」提示，口径与 NPC 档案一致 |
| 区域人数 | NPC 正式当前位置的子孙汇总；不会把常驻关系重复计数 |
| 地点事件 | 既有 eventArchive 投影的真实 locationId，保留状态及精确事件 ID 跳转 |
| 地点资产 | 复用 ownedAssets 的主角口径，只选房产／车辆的正式 locationId；不扩大他人经济资料的可见范围 |
| 地点详情 | WorldRecord 完整呈现真实字段，没有补造类型、背景、归属或描述 |
| 江河 | 确认设计的纯装饰 SVG，仅四个确切正式根城市 ID；其他根无江。无地理计算，aria-hidden |

## 验证数据

- 合成正式 fixture：重庆根、五级链、海外根／跨城旧地点、空根、当前地点、NPC 当前／常驻关系、主事件、主角房产及车辆。
- 纯投影：孤立节点、缺失父级、自指、两节点循环及其下级、缺失当前位置、空集合、80 级链。
- Chromium 压力：增加 250 个兄弟节点；包含超长中文及连续 300 个拉丁字符的名称，搜索末项、恢复选中及完整详情。
- 1920、1440、1280、1100、901px：根容器、树、详情均无横向溢出，独立纵向滚动。
- 390×844：原手机递归树与未修改 main 像素一致，功能不换为桌面示意图。
- 阅读前后完整 `loadGame()`（正式状态＋草稿）相等；纯浏览时 localStorage＋sessionStorage 的 SHA-256 不变，所有外部请求数为零。

压力记录见 [map-stress.json](validation/map-stress.json)。其中时间包括自动化等待、导航和截图，不作为独立渲染性能基准。
