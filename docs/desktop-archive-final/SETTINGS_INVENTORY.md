## 保存与焦点

- 游戏 PC：同一 ArchivePanel 系列的非模态设置，右侧 dock 可用，剧情／行动 inert。
- 首页 PC：同样的纸色表单，继续使用原生模态。
- 手机：原模态和表单布局不变；与 main 的七张页面像素对照相同。
- AI／记忆脏状态在分类切换、关闭和桌面 dock 跳转时仍要求明确继续编辑或放弃；二次确认是原生模态，先处理 Esc。
- 提示词与运行维持 main 原有的本地编辑／显式保存行为，没有新增自动保存或关闭拦截规则。
- 901px 切换保留同一个 dialog／SettingsPanel／密码输入 DOM；不会因桌面与手机容器切换而清除待保存密钥。
- 新凭证测试关闭 Playwright trace，只断言匹配布尔值；截图只包含密码掩码，渠道卡片地址经过既有安全格式化。
