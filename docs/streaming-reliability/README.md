针对反馈 `30aabc2f-41be-483f-8b48-9368a811aa27`。开发基线为 `main@1a2ed3355c48cfc2b3062f1b6d9aa7e985132968`。下面的测试使用合成正文和本地传输。玩家六次记录均为 HTTP 200、停在上游读取且要求手动重试。字节数、公开思考和正文标签均不足以推断该供应商实际发送过结束帧。

## 超时、结束及恢复

- **设置与快照。** 「设置 → 运行」保留原请求超时。缺少新设置时，正文流式空闲时限取原 `timeoutSeconds`，总时限取 `max(600, 空闲时限)`，出厂为 120/600 秒。空闲时限范围为 1–3600 秒，总时限为 1–7200 秒，保存及导入共同校验总时限 ≥ 空闲时限。正在执行的工作流使用启动快照。此改动无需迁移 GameState 或 IndexedDB。
- **阶段时钟。** 总时限从准备开始。准备阶段独立受原请求超时约束，至少给 10 秒并受总时限封顶；发出请求、收到响应头、上游完成分别进入等待响应头、等待首输出和包装恢复阶段。正文、公开思考或新工具参数可以续期空闲时限。字节、心跳、空 delta、相同 Gemini 累计快照和 UI 动画不续期。非流式传输保留原请求总超时，Variables、World、记忆和模型列表沿用原规则。
- **OpenAI 兼容与 DeepSeek。** 原始合法结束原因启动一次 250ms 尾帧等待。DONE、EOF 可提前结束。期限内继续读取 usage、错误、过滤及冲突；期限届满遇到残缺帧仍失败。没有 usage 时保持未知。文本兼容路径保留 main 已支持的独立 DONE，文学工具交付还必须通过工具名称、ID、数量、参数及包装恢复校验。Gemini 原生与 Anthropic 不使用这段尾帧通融，按原生完成语义处理。协议由实际渠道决定。
- **重试资格。** 已审计内置宿主、单次真实直连且能确认发生在上游连接、超时、读取中断或临时服务失败，才允许文学请求进入原重试策略。扩展关闭时仅沿用原指定 5xx 基础重试；打开时按设置额外 1 或 3 次。等待可以取消。实际经过中转、包装器失败、无法重建的脚本、主动取消、鉴权、明确额度耗尽及来源冲突分别保留停止保护。仅开启中转开关不构成中转使用证据。读取 HTTP 200 后失败不会触发改道。
- **请求隔离。** 每次重新进入宿主创建 UUID、AbortController、原始响应、协议记录和工具累积器。生成代理在第一个 await 之前领取并删除单次登记，结束或取消时清理。旧读取循环和包装恢复在输出前检查 signal；释放读取锁时无需等待外部取消 Promise。1118 脚本的 WAVE_PENDING_REQUESTS 按材料对象建表，在消费时删除，停止及切换事件清空旧登记。宿主另外用单次请求头绑定实际传输，避免跨存档领取。未知脚本继续手动处理。诊断仅增加时长、阶段、协议证据和重试决定等结构字段。
- **草稿与世界观。** 从头生成的尝试分别解析。继续已截断正文时沿用原续写入口。重新生成失败保留先前 ready 候选和已发布来源。未发布的替换正文仅能在同一仓库、同一草稿内容和有效存档身份下恢复本次签发的来源，同时重查持久化世界观指纹。存档实例、epoch、草稿 CAS 与正式提交校验仍生效。修复没有改动正式结算事务。

## 浏览器证据

真实回环 HTTP 服务分别返回 OpenAI 兼容 JSON/SSE。测试使用 Chromium 的 Desktop Chrome 与 Pixel 7 模拟、原生 Story 与加载两个实际脚本 iframe 的 1118，直接统计模型 POST，并分别在显式提交前后读取 IndexedDB 的回合、revision、候选和回执。服务端模型名含 gemini，实际请求协议为 OpenAI 兼容。测试不使用真实渠道或实体手机。

| 每种设备和模式各运行一次 | 每例 POST | 可观察结果 |
| --- | ---: | --- |
| 正常结束后长连接，40ms 后补 usage | 1 | 正常完成，客户端主动结束读取 |
| 慢速公开思考、慢速正文、非流式 JSON | 各 1 | 获得一份候选，显式结算一次 |
| 首次断流、首次仅心跳超时 | 各 2 | 首次无正式写入，第二次完成 |
| 重试等待期间把主世界书 A 换成 B | 2 | 两次请求均匹配 A，无一次匹配 B |
| 关闭扩展重试后断流、玩家主动取消 | 各 1 | 无成功候选，回合与 revision 不变，回执为零 |

36 个设备、模式与场景组合共发出 48 次 POST。28 个应成功的组合在生成后、提交前均为原 revision 且回执为零，显式提交后各有一张回执。8 个应停止的组合共 0 张回执。四个长连接对照从服务端写出结束原因到观察到连接关闭，实测分别为 521、289、310、321ms（桌面原生、桌面 1118、手机原生、手机 1118，包含浏览器调度与回环传输）。

逐次 POST、来源匹配、关闭耗时和存档读数见 [evidence.json](./evidence.json)。所有请求原文、正文、密钥和服务地址均从此摘要中省略。正文及脚本生成质量、真实第三方模型、真实渠道延迟和实体设备仍待授权环境验收。

## 工程与存档复跑

Node 24.19.0、npm 11.9.0、锁文件安装、Chromium 154.0.8037.57。四协议、文学宿主、中转、世界观和专项传输五个 Vitest 文件共 184 项通过。文学 HTTP 503 关闭扩展重试发 2 次，开启且允许 3 次重试时发 4 次；401 和明确额度耗尽的 429 均只发 1 次。取消、实际中转、存档及世界书跨标签的单独双端批次为 12 项通过。各批次有重叠，不合计作独立用例数。

旧 E2E 有两处夹具问题。在未修改产品代码的原 main 上，桌面、手机各复现一次。续写夹具现在通过仓库取回 #249 绑定的世界观；手动结算夹具在三阶段详情内选取按钮。两处均保留原有校验。完整工程检查、浏览器初跑及固定版本复跑的结果与 Actions 链接记录在 [Draft PR #257](https://github.com/WJT111222/HeiJinWangChao/pull/257)。

## 后续同步正式版

此分支目标为 main，仅使用 Beta 已有宿主。同步到 release/1.0 时保留正式版公共解析器的供应商结束标记、Anthropic 块索引和生命周期、终端工具唯一性，以及文学配置指纹和旧断点授权；在其实际宿主上重新验证后再开放重试资格。应逐项移植传输时限、读取清理和来源保护，复跑四协议、C1 与小猫之神 C2 的终端工具专项。Beta 文本的独立 DONE 兼容规则不能覆盖正式版更严格的上游契约。
