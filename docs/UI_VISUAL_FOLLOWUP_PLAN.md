# UI 纯视觉美化 · 后续更新计划

基线：`main@49ea869`（PR #104 合并后）。对应实现：分支 `ui/visual-polish-v2`（UI-2「夜幕金印 2.0」纯视觉美化）。

本文只记录**已讨论、暂缓**的视觉相关需求，供以后排期。文档归档不授权自动开发；每一项实施时都需要另立范围、测试与独立 PR。

## 0. 本次 UI-2 已实现的范围（不在本计划内）

UI-2 只换样式与排版，不新增存档字段、不改 AI 输出格式、不删减现有字段：

- 布局：左栏只放主角信息（身份、身体、情绪、现金、线上资金、七项穿戴、人物档案／经济与资产入口）；正文上方横栏放回合、阅读状态、游戏时间、地点、天气、环境（天气与环境分开显示）；右侧为世界资料印章栏与设置、返回首页。
- 正文：书页式排版、首行缩进，不做首字放大；对话保留说话人头像与名字。
- 资料面板在宽屏改为右侧抽屉；地图改为层级区块展示，只显示现有「地点资料」。
- 1200px 及以上使用左栏方案；901–1199px 与手机沿用 UI-1 布局。

## 1. 手机端单独设计

UI-2 只统一了阅读区样式（衬线正文、章回标题、剧本式对话、行动建议），手机端布局仍为 UI-1 的顶部状态条与底部导航。手机端的整体视觉另行设计、另立 PR。

## 2. 只需前端逻辑，不动存档

| 编号 | 内容 | 依据的现有数据 | 备注 |
| --- | --- | --- | --- |
| F1 | 城市底色：按开局城市切换辅助色（重庆雾青、上海霓蓝、哈尔滨冰银、广州木棉） | 地点树根节点 id（`chongqing` 等） | 辅助色只用于细线、圆点、淡背景光，不用于按钮 |

## 5. 建议顺序

1. 先落地已确认的纯视觉版本（第 0 节）。
2. F1、F2、F5：观感提升明显，且不碰存档。
3. B1＋B2：一次性加回合快照字段，同时打开每回合副标题、本回合变化和走势线。
4. F3、F4、F6、F7、B3 按需穿插。
5. A1、A2 放在最后，等提示词与校验稳定后单独立项。
