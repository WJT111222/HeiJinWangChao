# PR #212 独立复审核验：历史快照人物与地点详情

基线 `main@556e42bfed1308a19a487ba8417bba287cd223df`，修复前 `4d83b08a3630f2fe7bed917914ece54337d4277a`。使用同一合成历史节点，从只读预览的地图点击已建档人物。

## 根因与修改位置

历史预览的两种视口复用同一组资料组件（`src/ui/history/HistorySaves.tsx:49`、`src/ui/panels/Panels.tsx:23`）。日间历史弹窗在 `src/ui/history/history-saves.css:31` 设置纸色变量，姓名继承 #30291f，身份标签采用辅助色 #66563b。通用 `.npc-detail-heading` 在 `src/app/styles.css:2343` 取根元素的 `--panel`（#131614）。正式资料页在 `src/ui/archive.css:185` 和 `src/ui/archive-records.css:118` 的纸面规则要求游戏资料抽屉祖先；浏览器显示历史正文不匹配这些选择器。姓名和身份标记仍画在旧深底上。

地图的底色来自 `src/app/styles.css:828`，两层半透明网格叠在 #151d16 上。地点标题、层级与说明继承日间历史文字；路径按钮与选中地点自带可读的卡纸背景。详见[修复前 computed style、继承变量与逐层底色](computed-before.txt)。

产品改动仅两条样式（`src/ui/history/history-saves.css:164–165`）：日间历史阅读区内，NPC 标题和地点详情的背景色取历史卡纸；姓名首字印记取历史深金文字。只覆盖 background-color，地图网格继续绘制。正式档案及夜间历史组件都不匹配这两条规则。
